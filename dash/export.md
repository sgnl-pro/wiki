# Экспорт отчётов {#formats}

Перед выгрузкой выберите компанию, проект и дату отчёта. Если нужны актуальные сведения, сначала обновите карточки и проверьте их превью. Экспорт не является командой синхронизации источников.

| Формат | Где запустить | Для чего и что получается |
|---|---|---|
| XLSX целого отчёта | «Управление» → «Экспорт в Excel», администратор | Структура отчёта и данные карточек для обмена и подготовки привязки; не интерактивный просмотр моделей |
| PDF | «Отчёт», панель рядом с выбором даты, на компьютере | Изображения карточек; можно выбрать разбиение на страницы или длинную страницу |
| DOCX: данные | «Отчёт» → экспорт Word → режим данных | Документ с данными поддерживаемых типов карточек; состав может отличаться от полного набора карточек отчёта |
| DOCX: карточки | То же окно, режим карточек | Изображения карточек; подходит для сохранения внешнего вида |
| PPTX | «Отчёт», панель экспорта, на компьютере | Презентация из превью карточек; для 3D используется сохранённый снимок |
| XLSX из просмотра SLA | Кнопка экспорта внутри соответствующей карточки | Детализация её статистики; не файл импорта целого отчёта |
| CSV/XLSX публичных доступов | «Настройки» проекта → «Публичные доступы» | Реестр публичных ссылок; не содержимое 3D-моделей |

## Порядок действий {#steps}

1. Откройте «Отчёт» и выберите дату. Для экспорта нужны доступ к отчёту и видимые данные. В мобильном интерфейсе кнопки PDF, DOCX и PPTX скрыты — используйте компьютер.
2. Проверьте карточки, которые должны попасть в файл. Деактивация, статус карточки, права и поддержка типа влияют на доступное содержимое.
3. Выберите формат, а для PDF/DOCX — подходящий режим. Дождитесь окончания подготовки и сохраните файл.
4. Откройте файл и проверьте количество карточек, даты, подписи, числовые значения и изображения. Завершение скачивания само по себе не подтверждает полноту содержимого.

## 3D, видео и внешние страницы {#special}

Для 3D перед экспортом PPTX откройте карточку при редактировании отчёта, настройте вид модели и нажмите **«Снимок для превью»**. Сохранение фильтров, числовых значений превью и изображения — отдельные действия. После изменения модели при необходимости сделайте новый снимок. В презентации будет изображение, а не вращаемая BIM-модель.

Видео и встроенная внешняя страница не превращаются в работающий проигрыватель или сайт внутри статического документа. Для карточки 90 используется предусмотренное экспортом представление; внешняя система может запрещать получение изображения. Проверьте содержимое перед передачей: экспорт внешних страниц сопровождается предупреждением о конфиденциальной информации.

## Если результат неполный {#incomplete}

Откройте проблемную карточку и проверьте её загрузку. Для 3D проверьте сохранённый снимок; для DOCX сравните режим данных с режимом карточек: первый поддерживает не все типы. Проверьте скрытые карточки и выбранную дату отчёта. После исправления источника обновите карточку и повторите экспорт.

При ошибке захвата изображения отдельная карточка может отсутствовать в PPTX, хотя презентация скачалась. Сравнивайте результат с отчётом. Если повторная выгрузка не помогла, передайте в поддержку формат, режим, дату отчёта и тип отсутствующей карточки по [памятке](/dash/troubleshooting#support).
