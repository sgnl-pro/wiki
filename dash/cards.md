<summary><h3>Карточки 10. Общие</h3></summary>

- [10_Альбом](/dash/cards-10#card-10) — Карточка представляет собой фотоальбом, в который можно загрузить несколько фотографий.
- [11_ТЭПы](/dash/cards-10#card-11) — Технико-экономические показатели проекта.
- [12_Риски](/dash/cards-10#card-12) — Риски проекта с указанием их важности.
- [13_Видеотрансляция](/dash/cards-10#card-13) — Видеотрансляция со строительной площадки.
- [14_Динамика рабочих](/dash/cards-10#card-14) — График планового и фактического количества рабочих по дням.
- [15_Динамика универсальная](/dash/cards-10#card-15) — График изменения выбранного показателя, например числа работников или техники.
- [16_Процент готовности объекта](/dash/cards-10#card-16) — Плановая и фактическая готовность объекта в процентах.
- [17_Отчет](/dash/cards-10#card-17) — Карточка для отображения отчётной графической и текстовой информации.
- [18_Таблица из DOCS](/dash/cards-10#card-18) — Карточка показывает таблицу из XLSX-файла проекта DOCS.

</details>

<details>

<summary><h3>Карточки 20. Деньги</h3></summary>

- [20_Процент освоения денег](/dash/cards-20#card-20) — Плановое и фактическое освоение бюджета в процентах.
- [21_Общая накопительная по деньгам](/dash/cards-20#card-21) — Карточка отображает планирование бюджета строительства: оплата принятых конструкций, удержанные деньги, данные об авансе.
- [21_2_Общая накопительная по деньгам 2](/dash/cards-20#card-21-2) — Накопительные денежные показатели с обновлённым оформлением.
- [22_Освоение денег по месяцам](/dash/cards-20#card-22) — Плановые и фактические платежи по месяцам.
- [23_Освоение денег по месяцам с прогнозом](/dash/cards-20#card-23) — Платежи по месяцам с прогнозом освоения бюджета.
- [24_План-факт финансирования](/dash/cards-20#card-24) — Карточка показывает соблюдение графика финансирования и прибыль по месяцам.

</details>

<details>

<summary><h3>Карточки 30. Сроки</h3></summary>

- [30_Процент срока реализации](/dash/cards-30#card-30) — Сроки проекта: начало, окончание, длительность и прошедшие дни.
- [31_Вехи на проекте](/dash/cards-30#card-31) — Карточка показывает выполнение работ по вехам на выбранную дату.
- [32_График Excel](/dash/cards-30#card-32) — Вехи проекта и график работ с импортом из XML или XLSX.
- [33_График MPP](/dash/cards-30#card-33) — Карточка показывает график работ из файла MPP, загруженного в SIGNAL DOCS.
- [34_График MPP с вехами](/dash/cards-30#card-34) — Карточка показывает вехи из файла MPP и позволяет открыть график работ по нажатию на веху.
- [35_График Excel](/dash/cards-30#card-35) — Ранее созданный график Excel; новые карточки этого типа создать нельзя.

</details>

<details>

<summary><h3>Карточки 40. Объёмы</h3></summary>

- [40_Процент освоения объемов](/dash/cards-40#card-40) — Плановое и фактическое освоение объёмов работ в процентах.
- [41_План-факт по объемам](/dash/cards-40#card-41) — Карточка для отображения планового и фактического объема выполненных работ.
- [41_План-факт по объёмам MPP](/dash/cards-40#card-41-mpp) — Плановые объёмы из MPP-файла DOCS и фактические объёмы работ.
- [42_План-Факт-Замечания](/dash/cards-40#card-42) — Карточка показывает плановый и фактический объёмы работ, а также объём работ с замечаниями к качеству выполнения.
- [43_Темпы выполнения по объемам](/dash/cards-40#card-43) — Плановая и фактическая выработка по виду работ.
- [44_Прогноз выполнения](/dash/cards-40#card-44) — Прогноз объёмов и даты завершения работ по темпу выполнения.
- [46_План факт по объёмам с прогнозом](/dash/cards-40#card-46) — План, факт и прогноз объёмов работ по датам.
- [49_DOCS](/dash/cards-40#card-49) — Содержимое выбранной папки DOCS в отчёте.

</details>

<details>

<summary><h3>Карточки 50. 3D</h3></summary>

- [50_3D объёмы в BIM по датам](/dash/cards-50#card-50) — 3D-модель с плановыми и фактическими объёмами по датам.
- [51_3D объём в BIM за период](/dash/cards-50#card-51) — 3D-модель с плановыми и фактическими объёмами за период.
- [52_3D Цвета](/dash/cards-50#card-52) — 3D-модель с раскраской элементов.
- [52_2_3D Цвета 2](/dash/cards-50#card-52-2) — Проектная и строительная модели с отдельными настройками цветов.

</details>

<details>

<summary><h3>Карточки 60. DOCS</h3></summary>

- [61_Динамика замечаний в DOCS](/dash/cards-60#card-61) — Динамика числа замечаний DOCS по статусам.
- [62_Замечания DOCS](/dash/cards-60#card-62) — Статистика замечаний DOCS по статусам и периодам.
- [63_Общая по согласованиям в DOCS](/dash/cards-60#card-63) — Карточка показывает статистику согласований DOCS в виде круговой диаграммы.
- [64_Динамика согласований в DOCS 2](/dash/cards-60#card-64) — Динамика согласований DOCS по времени.
- [65_Реестр согласований в DOCS](/dash/cards-60#card-65) — Реестр согласований DOCS со статусами и сроками.
- [65_Согласования DOCS 2](/dash/cards-60#card-65-2) — Реестр согласований DOCS с поиском и фильтрами.
- [66_SLA по ролям](/dash/cards-60#card-66) — Карточка показывает долю проверок, завершённых в срок, по группам ответственных в проекте.
- [67_SLA по согласованиям](/dash/cards-60#card-67) — Карточка показывает долю проверок, завершённых в срок, по типам согласований в проекте.

</details>
