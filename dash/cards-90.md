# Вкладки{.tabset}
## 90_Интеграция
###### 90_Интеграция {#caed-90}

<span id="card-90"></span>

Карточка встраивает страницу внешнего сайта в отчёт DASHBOARD. Страница отобразится, если сайт разрешает открывать её во встроенном окне.

![image-1719554025085.png](https://lh7-rt.googleusercontent.com/docsz/AD_4nXe0YDGb1ebC4f7GBnaE75pDvs87Yzt6CrlxTh497byiKT50BGA2vYOV9aQIvLqU9KElMwDxupRnpSePQFPrwlq5ObnT6q3xXCqh86vXvulElMlRUW9p7nqJMfvscybBz9Ysje75b1L9w4V9eNam?key=8c0YXLpx6avetSwh7IusKA)

**Настройка карточки**

Вставьте адрес страницы в поле URL и нажмите «Сохранить». Если формат адреса неверный, карточка покажет ошибку.

![image-1719554083018.png](https://lh7-rt.googleusercontent.com/docsz/AD_4nXcrpOUzn9Hq0aneP8zqIai7LM8LC8wYnqWU4MfFxA-O6IvKaTzWawdHlHryUy1x4r0RAIXehNsLABIff7WMQI5DYesEVMRHV6phX1clqaz5Nnm_k6zGLf9YG_jlqPNl40RUlIBXSt56VHGvu3LVZw?key=8c0YXLpx6avetSwh7IusKA)

## 91_Ссылка
###### 91_Ссылка {#card-91}

Карточка открывает указанный адрес при нажатии. Для её превью можно добавить изображение.

![image-1677491297478.png](https://lh7-rt.googleusercontent.com/docsz/AD_4nXe4ZS92b0Z7IgoT7GM6pPgfYmgTSY433tSAvnP7DIAbw5us-5ktM7XMjkfNWuztv0EFReca7D2t8hN5Rxh_7h6G-JzypacDX0K4RyzaiWOwv4jUmeRFvffYOup_sTv--0FEC_FuFLxh-OkyfJ8w8g?key=XUt61_RjhC5-hTr3F0VvrA)

**Настройка карточки**

1. Вставьте адрес страницы.
2. При необходимости загрузите изображение для превью. Его можно обрезать, заменить или удалить.
3. Сохраните карточку.

![image-1677491318712.png](https://lh7-rt.googleusercontent.com/docsz/AD_4nXdMahylhzGFw_iLCw5HVsIxJMmEqsVn07WIZ2lB80TGgLnZTqQP4lcLEwMALdsxwr6KSU_io7DzkFuu1-bcVXwfnb28164vAIiUMa-8CTuxUnt9may6BoiwEDPKyXCSlU7Azuq6oYsew9eS_xxx2w?key=XUt61_RjhC5-hTr3F0VvrA)

## 93_Интеграция с Техзор
###### 93_Интеграция с Техзор {#cards-93}

<span id="card-93"></span>

Карточка строит график количества замечаний Техзора по статусам и датам на основе JSON-файла, загруженного в DOCS.

![График замечаний Техзора](/release_notes/2026.14_-_интеграция_с_техзор_1.png =1200x)

**Настройка карточки**

1. Выгрузите данные из Техзора в JSON-файл и загрузите файл в проект DOCS.
2. В настройках карточки выберите этот файл. После чтения файла карточка предложит объекты и подрядчиков из его данных; оставьте нужные значения. Можно выбрать несколько объектов и подрядчиков.
3. Выберите статусы замечаний и шаг группировки дат, затем сохраните карточку.

![Настройка карточки Техзора](/release_notes/2026.14_-_интеграция_с_техзор_2.png.png =1200x)

Если данные файла не загрузились, карточка показывает сообщение об ошибке. Проверьте выбранный JSON-файл в DOCS.
