# Диагностика {#start}

Сначала зафиксируйте компанию, проект, вкладку, дату отчёта и название карточки. Сравните результат под той же учётной записью: права администратора могут скрыть причину проблемы другого пользователя.

| Симптом | Что проверить | Следующее действие |
|---|---|---|
| Проект или нужная вкладка не видны | Компания, участие в проекте, доступ к модулю и роли | Обратиться к администратору компании/проекта; не создавать второй отчёт вместо поиска нужного |
| Нет кнопки заполнения или публикации | Права на карточку и отдельно на действия с отчётом | Проверить [матрицу доступов](/dash/access#where); заполнение карточки не даёт право публикации |
| Данные карточки нельзя ввести вручную | Есть ли назначенный диапазон таблицы или импортируемые поля | Изменить источник и синхронизировать; не отвязывать его без сохранения настроек |
| Группа бледная, карточки не редактируются | Деактивация группы или карточки | Администратору включить группу/карточку; сворачивание группы выполняет другую задачу |
| Карточка есть в «Управлении», но отсутствует в «Отчёте» | Публикация и выбранная дата отчёта, статус/деактивация карточки, права | Выбрать нужный опубликованный отчёт; проверить настройки карточки |
| Превью и открытая карточка показывают разные числа | Фильтры, отчётная дата, время обновления, сохранённые значения превью | Сверить источник и фильтры, обновить данные; для 3D отдельно проверить превью |
| Пустая статистика DOCS | Выбраны ли типы и статусы, есть ли подходящие записи за период | Снять ограничивающие фильтры, проверить исходный реестр DOCS и обновить карточку |
| У пользователя не открывается файл DOCS | Доступ к исходному файлу, его существование и версия | Открыть файл в DOCS под этим пользователем; проверить [правила доступа](/dash/access#docs) |
| «Онлайн» показывает вчерашние данные | Дата последнего обновления | Нажать «Обновить данные»; обновление не является непрерывным фоновым процессом |
| У 3D нет объёмов | Единицы выбранных работ, свойства объёма/площади/длины, типы и даты | Выбрать работы с одной единицей, проверить свойства модели и [настройки 50/51](/dash/cards-50) |
| 3D-модель не открывается | Обработка модели в DOCS, выбранный файл, доступ | Дождаться готовности модели; проверить открытие в DOCS и затем повторить просмотр |
| Не найдена публичная ссылка | Перевыпуск/удаление ссылки, существование карточки | Администратору проверить реестр ссылок и передать действующий адрес |
| Нет блока публичной ссылки | Тип карточки и роль пользователя | Использовать 50/51/52/52_2 и учётную запись администратора |
| Внешний сайт не виден в карточке 90 | Сайт открывается отдельно; разрешает ли встроенное окно | Использовать разрешённый адрес встраивания или карточку 91 для перехода на сайт |
| Нет видеотрансляции | Адрес HD/SD, H.264, работоспособность камеры и доступность потока для сервиса | Проверить поток с ответственным за камеры; не публиковать логин/пароль камеры в обращении |
| Уведомление не пришло | Получатели события публикации, email и состав роли, спам, личные настройки уведомлений | Проверить [настройки уведомлений](/dash/settings#notifications); обычное обновление данных и назначение старого отчёта текущим не равны первой публикации |
| Выгрузка отличается от экрана | Формат, режим, поддержка типа, снимок 3D, дата | Использовать [инструкцию экспорта](/dash/export#incomplete) |

# Ошибки привязки XLSX {#xlsx-errors}

Точный текст сообщения зависит от языка интерфейса. Ниже приведены причины ошибок, с которыми работает привязка.

| Причина | Как исправить |
|---|---|
| Лист не найден (`XLSX_E01_SHEET_NOT_FOUND`) | Проверить лист в книге и ссылку именованного диапазона; исправить и сохранить новую версию |
| Файл не найден (`XLSX_E02_FILE_NOT_FOUND`) | Проверить удаление файла, выбрать существующий файл в DOCS |
| Нет доступа (`XLSX_E03_FORBIDDEN`) | Проверить право чтения файла в DOCS у выполняющего синхронизацию |
| Ошибка скачивания (`XLSX_E04_DOWNLOAD_FAIL`) | Проверить доступность файла и сети, повторить после восстановления связи |
| Книга не читается (`XLSX_E05_PARSE_FAIL`) | Открыть книгу в редакторе, сохранить исправный `.xlsx`, загрузить новую версию |
| Файл слишком большой (`XLSX_E06_LARGE_FILE`) | Сократить книгу до 20 МиБ или меньше, вынести лишние данные в другие файлы |
| Именованный диапазон не найден (`XLSX_E07_DEFINED_NAME_NOT_FOUND`) | Создать или восстановить имя, обновить список диапазонов, повторно выбрать диапазон карточки |
| Ссылка диапазона не поддерживается (`XLSX_E08_DEFINED_NAME_UNSUPPORTED`) | Заменить формулу или `#REF!` обычной ссылкой на ячейки одного листа |
| Тип данных не совпадает с типом карточки | Восстановить полный блок из «Копировать данные карточки» именно нужного типа |
| Часть карточек обновилась, часть — нет | Обновлять неуспешные карточки по одной, исправляя конкретное сообщение. Успешные изменения уже сохранены |

# Что передать в поддержку {#support}

Если проверка не помогла, используйте [каналы поддержки SIGNAL](/general/support). В обращении укажите:

- адрес страницы DASHBOARD, компанию и проект;
- вкладку, дату отчёта, тип и название карточки;
- ожидаемый и фактический результат, точное время и текст ошибки;
- последовательность действий, браузер и повторяется ли проблема у другого пользователя;
- для файла — его название и версию, для таблицы — имя диапазона; приложите обезличенный минимальный пример при возможности;
- для экспорта — формат, режим и отсутствующие карточки.

Прикладывайте снимок экрана без паролей, токенов и чувствительных данных. Публичную ссылку на модель передавайте только через согласованный канал поддержки и только если её содержимое допустимо раскрывать получателям.
