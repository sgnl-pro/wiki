# Корпоративные карточки SLA {#overview}

Карточки **01_Общий SLA по ролям** и **03_SLA по ролям** создаются в «Отчёте компании». Доступ к просмотру этого отчёта задаёт администратор на уровне компании. В «Моём отчёте» и в плановом отчёте проекта эти типы не создаются.

Источник — статистика завершённых проверок и подписаний DOCS. Проценты SLA этапов определяются по [методике карточки 66](/dash/formulas#card-66). Настройки групп сохраняются в карточке; фильтры просмотра применяются к текущей выборке. Дата фильтра — дата завершения этапа.

# 01_Общий SLA по ролям {#card-01}

**Назначение:** сравнить группы ответственных по нескольким проектам и увидеть различия между проектами.

**Настройка:**

1. Откройте «Отчёт компании», создайте группу карточек и добавьте 01.
2. В настройках выберите проекты компании, которые должны участвовать в расчёте. Удалённые проекты не предлагаются для выбора.
3. Создайте группы ответственных, задайте названия и выберите пользователей или роли компании. Для каждой группы нужен хотя бы один ответственный.
4. Сохраните карточку и обновите данные отчёта.

**Просмотр:** откройте карточку, затем нужную группу и пользователя. Таблицы показывают показатели по проектам; детализация пользователя содержит завершённые этапы. Для поиска проблемных мест используйте фильтры имени, проекта и SLA на соответствующем уровне. Не суммируйте строки пользователей как число уникальных согласований.

**Расчёт:** для каждой группы показатель получается из SLA проектов с проверками. На превью показываются общий средний, минимальный и максимальный SLA и до десяти групп с наиболее низкими показателями. Подробности усреднения приведены [ниже](#aggregation).

**Обновление и экспорт:** «Обновить данные» обновляет превью отчёта компании. Для анализа открывайте подробные таблицы. Доступные выгрузки внутри карточек и экспорт целого проектного отчёта — разные операции; не переносите список форматов проектного отчёта на эту карточку.

**Если пусто:** проверьте выбранные проекты, группы, ответственных, наличие завершённых проверок и фильтры. Пустой набор проектов не означает выбор всех.

# 03_SLA по ролям {#card-03}

**Назначение:** получить статистику ответственных по проектам компании с показателями SLA, своевременного завершения и количеством проверок.

**Настройка:**

1. В «Отчёте компании» добавьте 03 и откройте настройки.
2. Создайте группы, назовите их и выберите ответственных — пользователей/роли компании.
3. Сохраните и нажмите «Обновить данные».

Проекты собираются по компании; в развёрнутом просмотре их можно ограничить фильтром. Если проекты в фильтре не выбраны, используются все предлагаемые проекты компании.

**Просмотр:** сначала доступны группы, затем пользователи и их завершённые проверки. Фильтруйте по проектам и датам завершения; на уровнях детализации используйте имя и порог SLA. На превью показываются сводные значения и до трёх групп с низкими показателями. Учитывайте [различие SLA и доли в срок](/dash/formulas#card-66).

**Обновление и экспорт:** обновите данные отчёта, затем откройте детализацию. При экспорте XLSX из просмотра проверяйте уровень выгрузки и полученные строки: отдельные выгрузки используют полный набор данных этого уровня и могут быть шире видимой после локального фильтра таблицы.

**Если показатели расходятся:** сравните выбранные проекты, даты, состав групп, наличие проверок и уровень усреднения. Один пользователь может присутствовать в нескольких группах; суммы строк групп не обязаны давать число уникальных этапов компании.

# Правила объединения показателей {#aggregation}

| Уровень | Как формируется |
|---|---|
| Пользователь по проектам | Объединяются уникальные этапы пользователя, затем усредняются их SLA; отдельно считается доля этапов в срок |
| Общая сводка 03 | Усредняются показатели пользователей, имеющих проверки; количество проверок, завершений в срок и просрочек суммируется |
| Строка группы 03 | Усредняются показатели включённых пользователей с ненулевым SLA; нулевой SLA не увеличивает знаменатель именно этого среднего |
| Группа 01 | Усредняются SLA проектов, в которых у группы есть проверки |
| Общий средний на превью 01 | Усредняются показатели групп; группы с нулевым итоговым SLA не увеличивают знаменатель общего среднего |

Пример для общей сводки 03: у одного пользователя одна проверка с SLA 100%, у второго — девять проверок со средним SLA 50%. Среднее пользователей — **75%**. Среднее всех десяти этапов было бы **55%**; это другой способ расчёта. Аналогично средняя доля в срок пользователей может отличаться от отношения общего количества своевременных этапов к общему количеству этапов.

Для 01, если у группы по двум проектам SLA 100% и 50%, её средний показатель равен 75% независимо от различий в числе проверок проектов. Поэтому для объяснения результата сверяйте детализацию, а не только итоговые количества.

Не трактуйте отсутствие статистики как 100% и не подменяйте нулевой результат отсутствием данных. Если нужен показатель с другой системой весов, выгрузите детализацию и явно укажите используемую методику расчёта.
