<span style="background: linear-gradient(45deg, #2D4E67, #112538); color: white; padding: 2px 6px; border-radius: 4px; font-size: 24px;">HUB</span>

**:fire: Уведомления в MAX**

Добавили MAX как новый канал доставки уведомлений: пользователь может [связать свой профиль](/hub/user#notifications) с ботом и выбрать MAX для нужных типов событий.

**:fire: Назначение контрагентов у пользователей**

Пользователю в [таблице](/hub/admin#company) можно назначить контрагента (компанию), в том числе массово для нескольких выбранных пользователей. Эта информация также попадает в экспорт. В дальнейшем компания и другие новые свойства пользователя будут использоваться при [заполнении форм](/forms/create) и для настройки ролей.

![2026.15_-_компании.png](/release_notes/2026.15_-_компании.png =1200x)

<span style="background: linear-gradient(45deg, #00D1FF, #0695D7); color: white; padding: 2px 6px; border-radius: 4px; font-size: 24px;">DOCS</span>

**:fire: Атрибуты в масках для наименований файлов**

В маски наименований теперь можно включать атрибуты файлов с типами `Текст`, `Дата` и `Список`. Такие маски можно использовать наряду с обычными масками без атрибутов. Для настройки маски с атрибутами нажмите на карандаш:

![2026.15_-_настройка_маски.png](/release_notes/2026.15_-_настройка_маски.png =1200x)

При загрузке, перемещении, копировании или переименовании файла система запрашивает значения атрибутов, формирует имя и одновременно сохраняет атрибуты. Система автоматически определяет атрибуты, если они уже заложены в имя исходного файла. В окне загрузки можно массово задавать значения атрибутов, которые есть у нескольких файлов. Значения атрибутов влияют на имя файла и наоборот:

![2026.15_-_переименование_файлов.png](/release_notes/2026.15_-_переименование_файлов.png =1200x)

**:fire: SIGNAL Viewer: замечания, публичные ссылки и облака точек PLY**

В SIGNAL Viewer реализовали возможность создавать замечания, прикрепляя к ним выбранные элементы модели. При открытии замечания выбранные элементы изолируются, камера фокусируется на них:

![2026.15_-_вьювер_-_замечания.png](/release_notes/2026.15_-_вьювер_-_замечания.png =1200x)

Также реализовали открытие моделей в SIGNAL Viewer по публичной ссылке и просмотр облаков точек в формате **Gaussian Splat PLY** без предварительной серверной конвертации.

**:sparkles: Доработки функционала**
- Добавили новый промпт `Стандарты` в ИИ-переработку текста «Стандарты»: он приводит текст к формальному деловому стилю, добавляет ссылки на нормативные документы и сохраняет исходный смысл.
- Добавили опцию в тип согласования, чтобы пользователи с доступом на создание согласования могли отменять процесс.
- Расширили окно перезапуска согласования.

**:hammer_and_wrench: Исправление ошибок**
- Поправили нанесение ручной подписи (факсимиле) в мобильной версии iOS.
- Устранили поворот ручной подписи в некоторых согласованиях.
- Убрали у пользователей с доступом на создание согласования возможность делать полный перезапуск.
- Вернули пользователям с доступом на редактирование возможность отменять завершенное согласование.
- Исправили ошибку, при которой открывался ранее выбранный файл при попытке добавить замечание из комплекта.
- Исправили ошибку, при которой пропадал плюсик для добавления оповещаемых при смене пользователя на роль.

<span style="background: linear-gradient(45deg, #7AA6CF, #7D96AD); color: white; padding: 2px 6px; border-radius: 4px; font-size: 24px;">API</span>

:sparkles: В [публичный API](/general/api) добавили методы:
- `PATCH /public/v1/projects` (изменение информации о проекте)
- `POST /public/v1/attributes/types/create`, `PATCH /public/v1/attributes/types` (добавление и изменение атрибутов проекта)
- `POST /public/v1/attributes/types/list/items/create`, `PATCH /public/v1/attributes/types/list/items` (добавление и изменение значений списочногых атрибутов проекта)
- `DELETE /public/v1/permissions/{permissionId:guid}` (удаление прав на папки)
- `GET /public/v1/reviews/types/names` (получение списка типов согласования проекта)
- `POST /public/v1/reviews/create` (создание комплекта согласования)
- `PATCH /public/v1/reviews/type` (изменение типа у комплекта согласования)
- `POST /public/v1/reviews/items/add`, `POST /public/v1/reviews/items/remove` (добавление и удаление файлов из комплекта согласования)
- `POST /public/v1/reviews/process/start` (запуск процесса согласования)
