**:fire: Открытие файлов Revit и Navisworks в SIGNAL Viewer**

Реализовали облачную конвертацию форматов RVT, NWD, NWC в нашем новом просмотрщике — просто загрузите модель в папку DOCS и откройте с помощью SIGNAL Viewer:

![2026-12-вьювер.png](/release_notes/2026-12-вьювер.png =1200x)

**:fire: Копирование передачи**

Добавили кнопку `Копировать` при наведении на передачу в реестре. При нажатии появляется диалоговое окно с параметрами и файлами, как у выбранной передачи. При необходимости их можно изменить и создать новую.

![2026.14_-_копирование_передачи.png](/release_notes/2026.14_-_копирование_передачи.png =1200x)

**:sparkles: Доработки функционала**
- Изменили параметры графики по умолчанию в SIGNAL Viewer.
- Добавили фильтр по PDF файлам в ленте с превью и вернули переключение между PDF файлами стрелками клавиатуры, в том числе при свернутой ленте.
- Добавили поддержку формата FBX в сборках.
- Добавили кнопку `Обновить версии` при просмотре сборки.

**:hammer_and_wrench: Исправление ошибок**
- Отключили переключение файлов в ленте превью с последнего на начальный.
- Увеличили ограничение вложенности папок до 16 при загрузке папки с устройства.

<span style="background: linear-gradient(45deg, #FF5867, #88383F); color: white; padding: 2px 6px; border-radius: 4px; font-size: 24px;">FORMS</span>

**:hammer_and_wrench: Исправление ошибок**
- Ввели запрет на удаление форм, которые используется в другой завершенной форме или на согласовании.
- Открыли возможность пользователям с доступом на создание форм редактировать свои черновики.
- Убрали столбцы `Текущий этап`, `Ответственный` и `Плановая дата` из таблиц форм, у которых нет этапов.
- Убрали столбец `Комментарий` при завершении формы без этапов.
- Убрали предупреждение о закрытии формы, если пользователь не вносил изменения.
- Добавили по умолчанию роль `Все пользователи` в доступы на создание и просмотр при добавлении новых форм в проект.
- Скрыли вкладку "Формы" в настройках проекта, если нет лицензии администратора на модуль FORMS.

<span style="background: linear-gradient(45deg, #A09EFF, #4B47FF); color: white; padding: 2px 6px; border-radius: 4px; font-size: 24px;">DASHBOARD</span>

**:fire: Карточка "93_Интеграция с Техзор"**

Реализовали новую карточку [93_Интеграция с Техзор](/dash/cards-90#cards-93) — аналитическая визуализация данных из Техзора, отображающая количество замечаний по каждому статусу на выбранную дату. Для импорта данных необходимо загрузить в DOCS JSON-файл, выгруженный из Техзора. Для настройки графика выберите объект, подрядчика, статусы замечаний и интервал отображения дат.

![2026.14_-_интеграция_с_техзор_1.png](/release_notes/2026.14_-_интеграция_с_техзор_1.png =1200x)

![2026.14_-_интеграция_с_техзор_2.png.png](/release_notes/2026.14_-_интеграция_с_техзор_2.png.png =1200x)

**:sparkles: Доработки функционала**
- В карточку [14_Динамика рабочих](/dash/cards-10#card-14) добавили интеграцию со СКУД (системой контроля и управления доступом). Карточка отображает динамику количества работников на объекте по данным СКУД. Для импорта данных необходимо загрузить в DOCS JSON-файл, выгруженный из СКУД. Для настройки графика выберите подрядчика:
![2026.14_-_скуд.png](/release_notes/2026.14_-_скуд.png =1200x)
- В [карточках 50 и 51](/dash/cards-50) добавили фильтрацию по подрядчику.
- В 3D-карточках изменили приоритизацию поиска элементов по легенде. Теперь поиск выполняется в следующем порядке: Issue Color → Color → User Color
