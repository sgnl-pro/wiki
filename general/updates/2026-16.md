**:sparkles: Доработки функционала**
- Добавили возможность отправлять уведомления HUB в мессенджеры MAX и Telegram.
- Увеличили допустимую длину названий материалов, нормативно-технической документации и видов работ.
- Добавили возможность назначить для проекта компании системное S3-хранилище.
- Добавили в HUB Tools сборки SIGNAL Basic.

---
<span style="background: linear-gradient(45deg, #00D1FF, #0695D7); color: white; padding: 2px 6px; border-radius: 4px; font-size: 24px;">DOCS</span>

**:fire: Копирование папок вместе с файлами**

Теперь при копировании структуры папок можно выбрать, нужно ли переносить файлы. Копирование доступно в пределах проекта, между проектами и между компаниями, если они используют одно S3-хранилище.

**:sparkles: Доработки функционала**
- Добавили отображение статуса, даты и времени конвертации файла для Tangl Viewer, Autodesk Forge и SIGNAL Viewer. Итоговая иконка файла показывает наиболее успешный из статусов.
- В SIGNAL Viewer добавили перевод свойств моделей.
- Убрали лишние файлы из оповещений по замечаниям комплекта.
- В оповещение о загрузке файла через диалог загрузки добавили ссылку на целевую папку.
- Доработали сравнение версий в Collabora.
- Добавили импорт и экспорт пустых папок без служебного TXT-файла.
- Доработали BIM-просмотрщик.

**:hammer_and_wrench: Исправление ошибок**
- Исправили кэширование устаревших прав доступа при входе пользователя в проект.
- Исправили загрузку файлов во вложениях замечаний, при генерации документов и работе с факсимиле.
- Исправили выгрузку множественной подписи в файле `.sig`.
- Исправили сохранение XLSX в Collabora.
- Исправили центрирование страницы при перелистывании PDF.
- Отключили отправку оповещений по удалённым замечаниям.

<span style="background: linear-gradient(45deg, #FF5867, #88383F); color: white; padding: 2px 6px; border-radius: 4px; font-size: 24px;">FORMS</span>

**:fire: Публичный API FORMS**

В публичном API открыли методы для чтения типов форм, групп, полей и этапов, а также для работы с экземплярами форм: поиска, получения, создания, изменения и завершения. Управление доступами, согласованиями и удалением форм через API не предоставляется.

**:fire: Создание формы из поля другой формы**

Если у пользователя есть право создавать формы требуемого типа, в поле-источнике доступна кнопка `Добавить`. Она открывает панель создания формы; после заполнения новую форму можно выбрать в исходном поле.

**:sparkles: Доработки функционала**
- Ограничили поле-источник в конструкторе одним типом форм.
- Скрываем столбец реестра для пользователя, если соответствующее поле скрыто во всех типах форм проекта.
- Отрефакторили проверки прав доступа в запросах.
- Поправили выравнивание типов форм в дереве.
