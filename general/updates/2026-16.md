<span style="background: linear-gradient(45deg, #2D4E67, #112538); color: white; padding: 2px 6px; border-radius: 4px; font-size: 24px;">HUB</span>

**:fire: Уведомления в MAX**

В [профиле пользователя](/hub/user#notifications) можно выбрать получение уведомлений SIGNAL не только по электронной почте, но и в мессенджере **MAX**. Ранее уведомления HUB приходили только на email. Настройка в общих параметрах уведомлений применяется и к отдельным разделам по умолчанию; при необходимости правила для конкретных событий можно изменить.

![2026.16_-_макс.png](/release_notes/2026.16_-_макс.png =900x)

**:sparkles: Доработки функционала**

- Увеличили максимальную длину названия в справочниках [видов работ, материалов и НТД](/hub/admin) до **1080 символов**. Для поля `Код` установили ограничение — **до 255 символов**. Теперь можно загружать и хранить записи с развёрнутыми наименованиями, которые раньше не помещались в поле.
- В [настройках S3-хранилищ](/hub/admin#settings) теперь можно выбрать системное хранилище для отдельного проекта компании. Раньше в этих настройках можно было подключать и настраивать хранилища компании, но нельзя было назначить системное S3 конкретному проекту:
![2026.16_-_s3.png](/release_notes/2026.16_-_s3.png =1200x)
- В [журнале действий компании](/hub/admin#log) ссылки из записей и карточек Dashboard открывают соответствующие объекты на вкладке «Управление», где можно продолжить работу с ними.


**<span style="color: #D32F2F;">СКРИНШОТ: журнал действий компании и переход к объекту на вкладке «Управление» Dashboard.</span>**

<span style="background: linear-gradient(45deg, #00D1FF, #0695D7); color: white; padding: 2px 6px; border-radius: 4px; font-size: 24px;">DOCS</span>

**:fire: Копирование папок вместе с файлами и версиями**

При [копировании структуры папок](/docs/folders#structure_tree) теперь можно выбрать один из двух вариантов: скопировать только папки или папки **вместе с файлами и всей историей их версий**. Раньше структуру папок и файлы приходилось копировать отдельными действиями.

Копирование папок с файлами доступно внутри компании — между проектами, использующими одно S3-хранилище. Между разными компаниями пока можно копировать только структуру папок без файлов.

**<span style="color: #D32F2F;">СКРИНШОТ: окно копирования структуры с выбором варианта «с файлами».</span>**

**:fire: Загрузка пустых папок**

В разделе [Документы](/docs/folders#uploadings) появилась кнопка `Загрузить папку`. Теперь можно перенести в проект структуру папок с компьютера, в том числе пустые папки. Раньше пустые папки не загружались: чтобы сохранить их в структуре, приходилось добавлять в каждую служебный TXT-файл.

**<span style="color: #D32F2F;">СКРИНШОТ: кнопка «Загрузить папку» и выбор папки с пустыми вложенными папками.</span>**

**:sparkles: Доработки функционала**

- В разделе [Документы](/docs/folders#statuses) по наведению на значок обработки теперь отображаются статус, дата и время конвертации отдельно для **Tangl Viewer**, **Autodesk Forge** и **SIGNAL Viewer**. Значок показывает наиболее успешный результат обработки. Ранее было невозможно быстро понять, в каком именно просмотрщике файл готов к открытию.
- В [работе с офисными документами](/docs/viewers#office) доработали сравнение версий в Collabora.
- Доработали [SIGNAL Viewer](/docs/viewers#bim):
  - нижнюю панель разделили на группы: действия с моделью, инструменты и настройки;
  - на узком экране группы кнопок переносятся на дополнительные строки, а не обрезаются и не перекрывают модель;
  - панели структуры модели, свойств и настроек можно изменить по ширине и высоте мышью или касанием;
  - при изменении размера окна или повороте мобильного устройства панели остаются в видимой области;
  - режим измерений сохраняет доступность всех кнопок и действий на узком экране.
- В диалоге загрузки файлов уведомление содержит ссылку на папку, в которую загружены файлы.
- При входе в проект пользователи сразу видят актуальные права доступа: ранее после изменения роли или доступа иногда требовалось очистить кэш браузера.

**<span style="color: #D32F2F;">СКРИНШОТ: SIGNAL Viewer на узком экране с перенесёнными группами нижней панели и изменяемой панелью свойств.</span>**

**:hammer_and_wrench: Исправление ошибок**

- При скачивании файла с несколькими присоединёнными ЭЦП в `.sig` сохраняются подписи всех подписантов. Ранее в выгруженном файле могла остаться только первая подпись.
- Исправили сохранение XLSX при [работе с офисными документами](/docs/viewers#office).
- Исправили центрирование страницы при перелистывании PDF.
- В уведомления о замечаниях комплекта больше не попадают файлы, которых нет в этом комплекте.
- Отключили отправку уведомлений по удалённым замечаниям.

<span style="background: linear-gradient(45deg, #FF5867, #88383F); color: white; padding: 2px 6px; border-radius: 4px; font-size: 24px;">FORMS</span>

**:fire: Создание связанной формы из поля-источника**

При [заполнении формы](/forms/create#3-заполнение-полей) пользователь может создать новую связанную форму прямо из поля-источника. Если у него есть право создавать формы требуемого типа, в раскрытом списке появляется кнопка `Добавить`. Она открывает панель создания формы; после заполнения новую форму можно выбрать в исходном поле.

Раньше для этого нужно было отдельно перейти в реестр нужного типа, создать форму, завершить её и затем вернуться к исходной форме. Теперь весь сценарий выполняется без выхода из текущей карточки.

**<span style="color: #D32F2F;">СКРИНШОТ: кнопка «Добавить» в поле-источнике и панель создания связанной формы.</span>**

**:fire: Публичный API FORMS**

В [публичном API](/general/api) доступны методы для:

- чтения типов форм, групп, полей и этапов;
- поиска и получения заполненных форм;
- создания, изменения и завершения форм.

Через API не предоставляются операции управления правами, маршрутами согласования, удалением и восстановлением форм. Это позволяет интеграциям передавать и получать данные форм, сохраняя управление доступом и согласованием внутри SIGNAL.

**:sparkles: Доработки функционала**

- В [конструкторе форм](/forms/builder) для одного поля-источника можно указать только один тип форм. Это исключает неоднозначность при выборе значения и упрощает настройку связанных форм.
- В реестре скрывается столбец, если соответствующее поле недоступно пользователю во всех типах форм проекта. Ранее такой пустой для пользователя столбец мог отображаться в таблице.
- Исправили выравнивание названий типов форм в дереве.

**:fire: SIGNAL Basic для Revit и Navisworks**

На странице [SIGNAL Tools](/tools) появились установщики **SIGNAL Basic for Revit** и **SIGNAL Basic for Navisworks**.
  
SIGNAL Basic — облегчённая сборка плагина для работы с моделями: в ней доступны базовые инструменты просмотра и настройки, измерения, наборы, отметка статусов выполнения, замечания, раскраска элементов, импорт и экспорт данных, а также вспомогательные утилиты.
