**:fire: Уведомления в MAX**

В [профиле пользователя](/hub/user#notifications) можно выбрать получение уведомлений SIGNAL не только по электронной почте, но и в мессенджере MAX. Настройка в общих параметрах уведомлений применяется и к отдельным разделам по умолчанию; при необходимости правила для конкретных событий можно изменить:
  
![2026.16_-_макс.png](/release_notes/2026.16_-_макс.png =900x)

**:sparkles: Доработки функционала**

- Увеличили максимальную длину названия в справочниках [видов работ, материалов и НТД](/hub/admin) до **1000 символов**. Длину поля `Код` увеличили **до 255 символов**. Теперь можно загружать и хранить записи с развёрнутыми наименованиями, которые раньше не помещались.
- В [настройках S3-хранилищ](/hub/admin#settings) теперь можно выбрать системное хранилище для отдельного проекта компании. Раньше в этих настройках можно было подключать и настраивать хранилища компании, но нельзя было назначить системное S3 конкретному проекту:
![2026.16_-_s3.png](/release_notes/2026.16_-_s3.png =1200x)
- В [логе организации](/hub/admin#log) добавили события по модулю DASHBOARD. Ссылки из записей открывают соответствующие отчёты:
![2026.16_-_логи_даш.png](/release_notes/2026.16_-_логи_даш.png =1200x)

**:fire: Копирование папок вместе с файлами и версиями**

При [копировании структуры папок](/docs/folders#structure_tree) теперь можно выбрать один из двух вариантов: скопировать только папки или папки **вместе с файлами и всей историей их версий**. Раньше структуру папок и файлы приходилось копировать отдельными действиями.

Копирование папок с файлами доступно внутри компании — между проектами, использующими одно S3-хранилище. Между разными компаниями пока можно копировать только структуру папок без файлов.

![2026.16_-_копирование_папок_с_файлами.png](/release_notes/2026.16_-_копирование_папок_с_файлами.png =900x)

**:fire: Загрузка и скачивание пустых папок**

В разделе [Документы](/docs/folders#uploadings) появилась кнопка `Загрузить папку`. Теперь можно перенести в проект структуру папок с компьютера, в том числе пустые папки. Папку также можно просто перетащить с устройства. Раньше пустые папки не загружались: чтобы сохранить их в структуре, приходилось добавлять в каждую служебный TXT-файл.
  
![2026.16_-_загрузить_папку.png](/release_notes/2026.16_-_загрузить_папку.png =600x)
  
Также добавили возможность скачивать пустые папки:
  
![2026.16_-_скачивание_пустой_папки.png](/release_notes/2026.16_-_скачивание_пустой_папки.png =450x)

**:sparkles: Доработки функционала**

- По наведению на значок обработки модели в папке теперь отображаются статус, дата и время конвертации отдельно для Autodesk Forge, Tangl Viewer и SIGNAL Viewer. Значок показывает наиболее успешный результат обработки:
![2026.16_-_отображение_статуса_модели.png](/release_notes/2026.16_-_отображение_статуса_модели.png =900x)
- В [работе с офисными документами](/docs/viewers#office) добавили сравнение файлов. Сейчас функция работает в стандартном режиме и позволяет сравнивать текущую версию с файлом, выбираемым на устройстве:
![2026.16_-_сравнение_файлов.png](/release_notes/2026.16_-_сравнение_файлов.png =1200x)
- Доработали [SIGNAL Viewer](/docs/viewers#bim):
  - нижнюю панель разделили на группы: действия с моделью, инструменты и настройки;
  - на узком экране группы кнопок переносятся на дополнительные строки, а не обрезаются и не перекрывают модель;
  - панели структуры модели, свойств и настроек можно изменить по ширине и высоте мышью или касанием;
  - при изменении размера окна или повороте мобильного устройства панели остаются в видимой области;
  - режим измерений сохраняет доступность всех кнопок и действий на узком экране;
  - поправили перевод системных свойств элементов при экспорте.
- В уведомление о загрузке файлов через окно загрузки добавили ссылку на папку, в которую загружены файлы.
  
**:hammer_and_wrench: Исправление ошибок**

- При скачивании файла с несколькими присоединёнными ЭЦП в `.sig` сохраняются подписи всех подписантов. Ранее в выгруженном файле могла остаться только первая подпись.
- Исправили центрирование страницы при перелистывании PDF.
- В уведомления о замечаниях комплекта больше не попадают файлы, которых нет в этом комплекте.
- Отключили отправку уведомлений по удалённым замечаниям.
- При входе в проект пользователи сразу видят актуальные права доступа: ранее после изменения роли или доступа иногда требовалось очистить кэш браузера.
- Понизили права на загрузку файла шаблона согласования с администратора организации до администратора проекта.
- Заменили пример шаблона в части атрибутов замечания: в предыдущем примере нельзя было использовать атрибуты, в названии которых содержатся пробелы.

**:fire: Создание связанной формы из поля-источника**

При [заполнении формы](/forms/create#3-заполнение-полей) пользователь может создать новую связанную форму прямо из поля-источника. Если у него есть право создавать формы требуемого типа, в раскрытом списке появляется кнопка `Добавить`. Она открывает панель создания формы; после заполнения новую форму можно выбрать в исходном поле. Из создаваемой форме в свою очередь можно создать ещё одну и так по цепочке.

Раньше для этого нужно было отдельно перейти в реестр нужного типа, создать форму, завершить её и затем вернуться к исходной форме. Теперь весь сценарий выполняется без выхода из текущей карточки.

![2026.16_-_новая_форма.png](/release_notes/2026.16_-_новая_форма.png =600x)

**:fire: Публичный API FORMS**

В [публичном API](/general/api) доступны методы для:

- чтения типов форм, групп, полей и этапов;
- поиска и получения заполненных форм;
- создания, изменения и завершения форм.

Это позволяет интегрировать модуль с внешними информационными системами, передавая и получая данные форм.
  
![2026.16_-_forms_api.png](/release_notes/2026.16_-_forms_api.png =1200x)

**:sparkles: Доработки функционала**

- В [конструкторе форм](/forms/builder) для одного поля-источника теперь можно указать только один тип форм. Это исключает неоднозначность при выборе значения и упрощает настройку связанных форм.
- При заполнении поля-источника вывели название типа формы, которая ожидается. Это особенно полезно, чтобы понять, какие формы требуется создать, если подходящих ещё нет в проекте.
- В реестре форм скрывается столбец, если соответствующее поле недоступно пользователю во всех типах форм проекта. Ранее такой пустой для пользователя столбец мог отображаться в таблице.

:hammer_and_wrench: Исправили выравнивание названий типов форм в дереве.

**:fire: SIGNAL Basic для Revit и Navisworks**

На странице [SIGNAL Tools](/tools) появились установщики **SIGNAL Basic for Revit** и **SIGNAL Basic for Navisworks**.
  
SIGNAL Basic — облегчённая сборка плагина для работы с моделями: в ней доступны базовые инструменты просмотра и настройки, измерения, наборы, отметка статусов выполнения, замечания, раскраска элементов, импорт и экспорт данных, а также вспомогательные утилиты.
