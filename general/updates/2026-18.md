**:fire: Компании и справочники для работы с формами**

В разделе [Компании](/hub/admin) расширили карточки организаций: можно указать сведения о юридическом лице, индивидуальном предпринимателе или физическом лице, роль организации, банковские реквизиты и членство в СРО. Раздел «Контрагенты» переименован в «Компании».

В справочниках [видов работ и материалов](/hub/admin) появились дополнительные свойства и связи с НТД. Расширен перечень единиц измерения; при импорте из Excel распространённые варианты их написания приводятся к единым значениям. Исправили сортировку групп с числовой частью в названии, например `А-1`, `А-2`, `А-10`, а также импорт позиций с номерами от 10 и отображение длинных названий.

<span style="background: linear-gradient(45deg, #00D1FF, #0695D7); color: white; padding: 2px 6px; border-radius: 4px; font-size: 24px;">DOCS</span>

**:fire: Сохранение документов замечаний в файлах проекта**

Документы, созданные по шаблону из [замечаний](/docs/issues), сохраняются в системных папках раздела «Файлы проекта». Для каждого типа замечания создаётся своя папка; внутри файлы можно группировать по году, месяцу и дню генерации. Формат вложенности задаётся в настройках типа замечания. Сгенерированный документ можно открыть или скачать из замечания. При повторной генерации сохраняется новая версия файла.

Системные папки создаются автоматически. Их нельзя переименовать или переместить как обычные папки; доступ к папке типа замечания можно синхронизировать с ролями, которым доступен этот тип.

**:fire: Статус файла после согласования**

В таблице [документов](/docs/folders) рядом со статусом согласования появился отдельный столбец с итоговым статусом файла в последней итерации. Столбец можно скрыть в настройках таблицы. Для статусов файлов расширили набор значков в настройках типа [согласования](/docs/reviews).

**:sparkles: Доработки функционала**

- Участник [согласования](/docs/reviews) может просмотреть файл из комплекта, даже если у него нет доступа к папке файла. В этом случае файл открывается в режиме просмотра.
- Ответственные за просроченные [замечания](/docs/issues) и этапы согласования получают напоминания о нарушении срока. Уведомления включены по умолчанию и отправляются ежедневно в течение двух недель после просрочки.
- При перемещении папки нельзя выбрать её собственную вложенную папку. Также запрещены перенос и копирование папки без масок именования внутрь папки с масками.

**:hammer_and_wrench: Исправление ошибок**

- Файлы снова копируются между проектами в папку с настроенными масками именования.
- При создании замечания из PDF отображаются атрибуты, назначенные его типу.
- Пользователь, удалённый из проекта, больше не получает уведомления об изменениях замечания.

<span style="background: linear-gradient(45deg, #FF5867, #88383F); color: white; padding: 2px 6px; border-radius: 4px; font-size: 24px;">FORMS</span>

**:fire: Уведомления о формах и этапах согласования**

Пользователям доступны уведомления о создании, изменении и завершении [форм](/forms/create), а также о запуске согласования и событиях его этапов: назначении ответственного, изменении срока, приближении плановой даты и просрочке. Получатели определяются по роли пользователя в форме или этапе.

**:fire: Файлы и системные папки форм**

При заполнении [формы](/forms/create) в поле с файлом можно выбрать документ из DOCS или загрузить файл с устройства. Загруженные вложения сохраняются в системных папках «Файлов проекта».

Документы DOCX, созданные по шаблону формы, также сохраняются в системной папке её типа. Из формы можно открыть созданный документ или перейти к папке с ним. В настройках типа формы можно создать или синхронизировать системную папку и задать группировку файлов по дате.

**:sparkles: Доработки функционала**

- В [конструкторе](/forms/builder) можно прикрепить к типу формы шаблон DOCX по умолчанию. При добавлении типа в проект этот шаблон передаётся в настройки проекта; затем его можно заменить.
- В таблицах форм появились пользовательские настройки столбцов и наборы настроек отображения. Можно выбрать видимые поля и порядок столбцов.
- При импорте форм из Excel список разбивается на партии по 200 записей, поэтому за одну операцию можно загрузить больше 200 форм.
- Значения связанных форм и справочников можно использовать в отображаемом названии формы.
- Если все поля этапа скрыты от пользователя, заголовок этого этапа не показывается в списке полей.

:hammer_and_wrench: Ответственный за этап формы может завершить его без отдельного права на редактирование, если на этапе нет полей или их значения не менялись. В этом случае лишний запрос на сохранение формы больше не отправляется; кнопка сохранения черновика без изменений недоступна.
