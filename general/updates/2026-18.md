**:fire: Сохранение сгенерированных документов из замечаний в файлах проекта**

Документы, созданные по шаблону из [замечаний](/docs/issues#issue_template), сохраняются в системных папках раздела [«Файлы проекта»](/docs/folders). Для каждого типа замечания создаётся своя папка; внутри файлы можно группировать по году, месяцу и дню генерации. Сгенерированный документ можно открыть или скачать из замечания. При повторной генерации сохраняется новая версия файла:

![2026.18_-_замечание_и_файл.png](/release_notes/2026.18_-_замечание_и_файл.png =1200x)

Формат вложенности задаётся в настройках типа замечания. Системные папки создаются автоматически. Их нельзя переименовать или переместить как обычные папки; доступ к папке типа замечания можно синхронизировать с ролями, которым доступен этот тип:

![2026.18_-_настройки_замечания.png](/release_notes/2026.18_-_настройки_замечания.png =1200x)

**:fire: Статус файла согласования в папке**

В таблице документов рядом со статусом согласования появился отдельный столбец с итоговым статусом файла в последней итерации. Столбец можно скрыть в настройках таблицы:

![2026.18_-_статусы_файлов_в_папке.png](/release_notes/2026.18_-_статусы_файлов_в_папке.png =1200x)

Для статусов файлов расширили набор значков в настройках типа [согласования](/docs/reviews):

![2026.18_-_настройка_статусов_файлов.png](/release_notes/2026.18_-_настройка_статусов_файлов.png =600x)

**:sparkles: Доработки функционала**

- Участник согласования может просмотреть файл из комплекта, даже если у него нет доступа к папке файла. В этом случае файл открывается в режиме просмотра.
- Ответственные за просроченные замечания и этапы согласования получают напоминания о нарушении срока. Уведомления включены по умолчанию и отправляются ежедневно в течение двух недель после просрочки.
- Папку без масок именования теперь нельзя переместить или скопировать в папку, где настроены маски. Это предотвращает появление вложенной структуры, к которой правила именования не применяются.

**:hammer_and_wrench: Исправление ошибок**

- При перемещении папки её вложенные папки больше нельзя выбрать местом назначения: кнопка «Переместить» остаётся недоступной.
- Файлы снова копируются между проектами в папку с настроенными масками именования.
- При создании замечания из PDF отображаются атрибуты, назначенные его типу.
- Пользователь, удалённый из проекта, больше не получает уведомления об изменениях замечания.

<span style="background: linear-gradient(45deg, #FF5867, #88383F); color: white; padding: 2px 6px; border-radius: 4px; font-size: 24px;">FORMS</span>

**:fire: Загрузка файлов с устройства и системные папки форм**

При заполнении [формы](/forms/create) в поле с файлом можно выбрать документ из DOCS или загрузить файл с устройства. Загруженные вложения сохраняются в системных папках. Документы DOCX, созданные по шаблону формы, также сохраняются в системной папке её типа. Из формы можно открыть созданный документ или перейти к папке с ним:

![2026.18_-_форма_и_файл.png](/release_notes/2026.18_-_форма_и_файл.png =1200x)

В настройках типа формы можно создать или синхронизировать системную папку и задать группировку файлов по дате:

![2026.18_-_настройки_формы.png](/release_notes/2026.18_-_настройки_формы.png =1200x)

**:sparkles: Доработки функционала**

- В [профиле пользователя](/hub/user#notifications) можно настроить уведомления FORMS: выбрать события для форм и этапов согласования, каналы доставки и объединение сообщений:
![2026.18_-_настройка_уведомлений_форм.png](/release_notes/2026.18_-_настройка_уведомлений_форм.png =900x)
- В [конструкторе](/forms/builder) можно прикрепить к типу формы шаблон DOCX по умолчанию. При добавлении типа формы в проектв [настройки проекта](/forms/settings) этот шаблон передаётся, его можно заменить на свой и затем при необходимости вернуть обратно или актуализировать при появлении новой версии:
![2026.18_-_замена_шаблона_формы.png](/release_notes/2026.18_-_замена_шаблона_формы.png =600x)
- В таблицах форм появились пользовательские настройки столбцов и наборы настроек отображения. Можно выбрать видимые поля и порядок столбцов:
![2026.18_-_настройки_столбцов_форм.png](/release_notes/2026.18_-_настройки_столбцов_форм.png =1200x)
- При импорте форм из Excel список разбивается на партии по 200 записей, поэтому за одну операцию теперь можно загрузить больше 200 форм.
- Значения связанных форм и справочников можно использовать в отображаемом названии формы.
- Если все поля этапа скрыты от пользователя, заголовок этого этапа не показывается в списке полей.

:hammer_and_wrench: Ответственный за этап формы может завершить его без отдельного права на редактирование, если на этапе нет полей или их значения не менялись. Кнопка «Сохранить черновик» недоступна, если изменений нет.
