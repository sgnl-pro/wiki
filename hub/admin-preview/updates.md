**Обозначения**
:fire: — новые возможности
:sparkles: — доработки функционала
:hammer_and_wrench: — исправление ошибок

----
**[2026.16](/general/updates/2026-16)** ^31.08.2026^

:sparkles: В настройках S3-хранилищ добавили выбор системного хранилища для отдельного проекта. В логах организации появились события DASHBOARD.

----
**[2026.15](/general/updates/2026-15)** ^17.08.2026^

:fire: У пользователей компании можно назначать контрагента, в том числе массово. Добавили фильтр во вкладке «Роли».

----
**[2026.13](/general/updates/2026-13)** ^20.07.2026^

:sparkles: На вкладках «Пользователи» и «Проекты» добавили постраничный просмотр пользователей.

----
**[2026.12](/general/updates/2026-12)** ^02.07.2026^

:sparkles: У проекта добавили настройку «Проект по умолчанию для новых пользователей». Администраторы могут редактировать данные пользователя, если он состоит только в одной компании.

----
**[2026.11](/general/updates/2026-11)** ^18.06.2026^

:sparkles: Добавили роль «Как в организации» для синхронизации ролей пользователя между компанией и проектом.

----
**[2026.10](/general/updates/2026-10)** ^04.06.2026^

:sparkles: При экспорте пользователей компании добавили столбец «Проекты».

----
**[2026.8](/general/updates/2026-8)** ^07.05.2026^
  
:sparkles: В таблицу пользователей добавили дату последнего входа.
  
----
**[2026.7](/general/updates/2026-7)** ^23.04.2026^
  
:sparkles: Реализовали «бесконечный» скролл логов компании, теперь события быстрее отображаются и можно экспортировать в Excel отображаемые записи.

:hammer_and_wrench: Устранили ряд небольших ошибок при работе с проектами, а также исправили отображение пользователей, добавленных через ldap.
  
----
**[2026.6](/general/updates/2026-6)** ^09.04.2026^
  
:hammer_and_wrench: Сделали выбор календаря у проекта обязательным.
  
----
**[2026.5](/general/updates/2026-5)** ^26.03.2026^
  
:sparkles: Реализовали проверку и предупреждение при удалении роли, если она используется в типах замечаний или согласований.
  
:sparkles: Добавили отдельную форму пригласительного письма для пользователей с SSO.
  
----
**[2026.1](/general/updates/2026-1)** ^22.01.2026^
  
:sparkles: Добавили выделение пользователей в общей таблице через <kbd>Shift</kbd>.

:hammer_and_wrench: Поправили поведение кнопки **Войти** на главной странице после регистрации или восстановления пароля.
  
----

----
**[2025.35](/general/updates/2025-35)** ^13.11.2025^
  
:hammer_and_wrench: Поправили отображение лупы при поиске в браузере Firefox.
