**Обозначения**
:fire: — новые возможности
:sparkles: — доработки функционала
:hammer_and_wrench: — исправление ошибок

----
**[2026.16](/general/updates/2026-16)** ^31.08.2026^

:fire: Добавили получение уведомлений SIGNAL в MAX. Канал можно включить в общих настройках и настроить отдельно для конкретных событий.

----
**[2026.13](/general/updates/2026-13)** ^20.07.2026^

:sparkles: Добавили уведомление об открытии комплекта согласования ответственным за связанные замечания. По умолчанию уведомление выключено.

----
**[2026.12](/general/updates/2026-12)** ^02.07.2026^

:sparkles: Вывели в профиль пользователя информацию о привязанном Telegram.

----
**[2026.9](/general/updates/2026-9)** ^21.05.2026^

:fire: Добавили расширенные настройки уведомлений: выбор событий по модулям, объединение уведомлений и индивидуальные настройки отдельных событий.

----
**[2025.41](/general/updates/2025-41)** ^25.12.2025^

:hammer_and_wrench: Поправили поведение кнопки **«Войти»** на главной странице после регистрации или восстановления пароля.

----
**[2025.35](/general/updates/2025-35)** ^13.11.2025^

:hammer_and_wrench: Поправили отображение значка поиска в Firefox.

----
**[2025.33](/general/updates/2025-33)** ^30.10.2025^

:sparkles: Сделали, чтобы при входе в HUB открывалась последняя выбранная компания.

----
**[2025.32](/general/updates/2025-32)** ^23.10.2025^

:hammer_and_wrench: Исправили выход из системы со вкладок профиля.

----
**[2025.27](/general/updates/2025-27)** ^18.09.2025^

:fire: Реализовали новый дизайн интерфейса HUB.

> Информация о более ранних обновлениях доступна в закрытом Telegram-канале для пользователей SIGNAL. Для добавления [обратитесь в поддержку](/general/support).
