**Обозначения**
:fire: — новые возможности
:sparkles: — доработки функционала
:hammer_and_wrench: — исправление ошибок

----
**[2026.16](/general/updates/2026-16)** ^31.08.2026^

:fire: В поле `Форма` можно создать связанную форму, не переходя в другой реестр, если у пользователя есть право на её создание.

:sparkles: В реестре скрывается столбец, если соответствующее поле недоступно пользователю во всех типах форм проекта.

----
**[2026.15](/general/updates/2026-15)** ^17.08.2026^

:fire: Добавили поля для выбора замечаний, комплектов согласования и передач проекта DOCS, справочников HUB, контрагентов и пользователей компании.

:fire: Реализовали экспорт и импорт форм из XLSX.

:hammer_and_wrench: Добавили открытие файлов, если у пользователя есть доступ только на просмотр формы и самого файла.

:hammer_and_wrench: Исправили отправку значения `Нет` у поля типа `Да/Нет`, если пользователь не менял переключатель.

----
**[2026.14](/general/updates/2026-14)** ^03.08.2026^

:hammer_and_wrench: Ввели запрет на удаление форм, которые используются в другой завершённой форме или находятся на согласовании.

:hammer_and_wrench: Открыли возможность пользователям с доступом на создание форм редактировать свои черновики.

:hammer_and_wrench: Убрали столбцы `Текущий этап`, `Ответственный` и `Плановая дата` из таблиц форм без этапов.

:hammer_and_wrench: Убрали поле `Комментарий` при завершении формы без этапов.

:hammer_and_wrench: Убрали предупреждение о закрытии формы, если пользователь не вносил изменения.

----
**[2026.13](/general/updates/2026-13)** ^20.07.2026^
  
:sparkles: Сняли ограничение с администратора проекта на редактирование завершенных форм.

:sparkles: Добавили предупреждение при закрытии формы, в которую внесли изменение и не сохранили.

:sparkles: Добавили открытие форм из полей других форм в таблице.

:hammer_and_wrench: Поправили сортировку отображаемых полей в имени формы.
