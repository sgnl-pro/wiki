**Обозначения**
:fire: — новые возможности
:sparkles: — доработки функционала
:hammer_and_wrench: — исправление ошибок

----
**[2026.19](/general/updates/2026-19)** ^23.10.2026^

:fire: Добавили выбор типа согласования DOCS для создания комплектов из завершённых форм.

:sparkles: Наблюдателями типа формы проекта можно назначать отдельных пользователей вместе с ролями.

----
**[2026.18](/general/updates/2026-18)** ^28.09.2026^

:fire: Для типа формы в проекте можно создать системную папку и настроить группировку файлов по датам. Доступы папки можно синхронизировать с доступами типа.

:sparkles: Шаблон DOCX по умолчанию передаётся из конструктора при добавлении типа формы в проект; затем его можно заменить или восстановить.

----
**[2026.17](/general/updates/2026-17)** ^14.09.2026^

:fire: Добавили настройку значений полей по умолчанию для отдельного проекта. Значения автоматически подставляются при создании экземпляров формы и могут отличаться от настроек исходного типа формы в конструкторе.

----
**[2026.14](/general/updates/2026-14)** ^03.08.2026^

:hammer_and_wrench: При добавлении типа формы в проект для роли `Все пользователи` по умолчанию включены права на чтение и создание.

:hammer_and_wrench: Скрыли вкладку "Формы" в настройках проекта, если нет лицензии администратора на модуль FORMS.

----
**[2026.13](/general/updates/2026-13)** ^20.07.2026^
  
:sparkles: Добавили корзину для просмотра и восстановления удалённых типов форм в проекте.
