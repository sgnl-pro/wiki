SIGNAL Forms XML — отдельное приложение для подготовки XML из данных проекта FORMS. В первой версии поддерживаются акты освидетельствования скрытых работ (АОСР), отдельный титульный лист и разделы общего журнала работ (ОЖР).

## Запуск приложения {#launch}

Приложение поставляется отдельной сборкой. Распакуйте папку **SIGNAL-Forms-XML** целиком и следуйте инструкции **START-HERE.txt** из этой сборки. Для локального запуска используется Node.js 24: в терминале из папки приложения выполните `node scripts/serve.mjs`, затем откройте указанный сервером адрес в браузере. Окно терминала должно оставаться открытым во время работы.

## Подготовка проекта {#prepare}

Для работы нужны заполненные формы проекта и [интеграция SIGNAL](/hub/admin#integrations) с доступом к этим данным. Подготовьте связанные сведения об объекте строительства, организациях, представителях и документах. Для журнала нужна основная форма журнала со связями на титульный лист и его разделы. Состав реквизитов зависит от выбранного документа и фактически используемых разделов.

Приложение использует существующие значения и связи между формами. Не дублируйте сведения только ради XML, если их можно получить из связанной формы. Проверьте полноту исходных данных и вложений до формирования пакета.

## Подключение и привязки {#mapping}

1. Откройте SIGNAL Forms XML и подключитесь к SIGNAL с помощью **Client ID** и **Client Secret** интеграции, добавленной в нужный проект. Эти данные вводятся в приложении.
2. Выберите проект и загрузите его формы.
3. Выберите вид документа: **АОСР**, **Полный ОЖР** или **Титульный лист ОЖР**.
4. В настройках выгрузки сопоставьте типы форм и поля проекта с реквизитами XML. Используйте **«Автопривязку»**, затем проверьте результат и уточните соответствия вручную.

Количество ненайденных привязок относится к каталогу реквизитов. Оно само по себе не означает, что выбранный документ содержит столько же ошибок: часть реквизитов нужна только для отдельных разделов или вариантов участников. Окончательный результат оценивайте по проверке конкретных документов.

## Проверка и выгрузка {#export}

Выберите исходную форму и запустите подготовку пакета. Для полного ОЖР при необходимости задайте период. Приложение проверяет данные и соответствие XML XSD-схемам, показывает ошибки и предупреждения.

В строгом режиме ошибки блокируют готовый пакет. В черновом режиме обязательные пропуски могут заменяться заглушками: такой пакет предназначен для проверки подготовки данных. После успешного формирования нажмите **«Скачать ZIP»**. Архив содержит XML и вложения документов.

Проверьте содержание выгруженных файлов. Успешная проверка XSD подтверждает структуру XML, но не заменяет проверку правильности организаций, ролей участников, реквизитов и приложенных документов.

## Ограничения MVP {#limitations}

> Это первая версия отдельного инструмента подготовки XML. Полный ОЖР пока выгружается в черновом режиме: обработка обязательных блоков XML-подписей требует доработки. Подписание УКЭП и передача или регистрация документов в системе стройнадзора выполняются отдельно. Черновой ZIP с заглушками не является готовым пакетом для передачи получателю.
{.is-warning}

Настройка привязок зависит от используемых типов форм. Перед рабочей выгрузкой проверьте, что приложение прочитало все необходимые поля, а выбранные связи соответствуют нужным ролям и разделам документа.
