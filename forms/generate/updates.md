**Обозначения**
:fire: — новые возможности
:sparkles: — доработки функционала
:hammer_and_wrench: — исправление ошибок

----
**[2026.19](/general/updates/2026-19)** ^23.10.2026^

:fire: Добавили генерацию PDF из DOCX завершённой формы и открытие результата в просмотрщике DOCS.

:fire: Представили отдельное приложение SIGNAL Forms XML для подготовки АОСР и ОЖР в формате XML (MVP).

:sparkles: В шаблонах DOCX доступны свойства связанных замечаний, согласований и передач.

----
**Структура справки и примеры шаблонов** ^21.10.2026^

Вынесли перечень форм и их полей в [отдельную статью](/forms/library) с собственной [историей изменений](/forms/library/updates).

Уточнили примеры шаблонов: числовое значение выводится без единицы измерения, диапазон дат — через дефис, имена вложений — в цикле; для свойств этапов используется путь `_stage.N`.

----
**[2026.18](/general/updates/2026-18)** ^28.09.2026^

:fire: Созданный по шаблону DOCX сохраняется в системной папке типа формы. Из карточки формы его можно открыть или перейти к папке с документом.

----
**[2026.17](/general/updates/2026-17)** ^14.09.2026^

:sparkles: Расширили фильтр `uniqueBy`: теперь он исключает повторяющиеся значения не только внутри одного массива, но и между массивами связанных форм, обрабатываемых во вложенном цикле.

----
**[2026.15](/general/updates/2026-15)** ^17.08.2026^

:fire: Значительно расширили синтаксис шаблонов DOCX: добавили условия, циклы, выражения, изображения, гиперссылки и системные данные формы и этапов.

:sparkles: Улучшили проверку шаблонов: перед генерацией система сообщает о неизвестных ключах и ключах без значений, а синтаксические ошибки DOCX и тегов показываются с пояснением.

----
**[2026.13](/general/updates/2026-13)** ^20.07.2026^

:sparkles: Добавили примеры шаблонов DOCX для новых типов форм. Изменения состава библиотеки приведены в [истории перечня форм](/forms/library/updates).
