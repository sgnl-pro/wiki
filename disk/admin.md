Массовая установка DOCS Disk на компьютеры с Windows 10 и Windows 11. Обычная установка и работа с приложением описаны в [руководстве пользователя](/ru/disk/user).

## Пакеты и установка

Установщик — один файл `.msi`. В пакет входит всё необходимое, включая .NET. Для установки нужны права администратора. Облачная и on-premise версии могут быть установлены одновременно и не мешают друг другу.

## Тихая установка и групповая политика

Тот же `.msi` поддерживает тихую установку и развёртывание через групповую политику.

Пример тихой установки — замените путь на путь к вашему пакету:

```powershell
msiexec /i "C:\Install\DOCS-Disk.msi" /qn
```

Для on-premise дополнительно передайте адрес сервера в свойстве `HUB`. При установке через групповую политику задайте его через MST.

| Свойство MSI | Назначение | Можно изменить в приложении |
| --- | --- | --- |
| `HUB` | Адрес собственного сервера DOCS; обязателен для on-premise | Нет |
| `AUTORUN` | Начальное значение автозапуска | Да |
| `DRIVELETTER` | Начальная буква диска | Да |
| `COMPANY` | Компания по умолчанию | Да |

`AUTORUN`, `DRIVELETTER` и `COMPANY` доступны в обоих пакетах и задают начальные настройки пользователя.

## Адрес собственного сервера

Если ваша организация использует собственный сервер DOCS — **on-premise**, — установщик попросит указать его адрес.

> **Адрес сервера обязателен.** Он задаётся один раз при установке, и изменить его в приложении нельзя. Если приложение запустится без адреса, оно сообщит об этом и предложит переустановить его.
{.is-warning}

Облачная и on-premise версии могут быть установлены на одном компьютере одновременно и не мешают друг другу.

## Обновление и восстановление

Повторный запуск **того же пакета** предлагает действия **«Переустановить»** для восстановления установки и **«Удалить»**. Более новый пакет обновляет установленную версию на месте, в том числе версию, установленную прежней программой установки.

## После установки или обновления

После первой установки перезапустите Проводник или повторно войдите в Windows, чтобы заработало копирование папок напрямую в DOCS. После обновления перезапуск Проводника также может потребоваться для загрузки актуального расширения контекстного меню и его значков.
