**Где находятся кнопки:** вкладка **«Инструменты»**. Настройки открываются кнопкой **«Настройки»** на этой же вкладке.

Быстрый подсчёт суммирует свойства выбранных элементов. Например, можно выбрать элементы через группу этажа и получить их общий объём.

**Содержание:** [Инструменты](#calculation-tools) · [Настройки](#calculation-settings)

## Быстрый подсчёт {.tabset}

### Инструменты

#### Инструменты {#calculation-tools}

Выделите нужные элементы и нажмите кнопку показателя.

| Кнопка | Что показывает |
| --- | --- |
| **Объём** | Суммарный объём по настроенным свойствам |
| **Площадь** | Суммарную площадь по настроенным свойствам |
| **Длина** | Суммарную длину по настроенным свойствам |
| **Кол-во** | Количество выбранных элементов |
| **Вес** | Суммарный вес по настроенным свойствам |
| **Пользоват. свойство** | Подсчёт по выбранному пользовательскому типу, созданному в настройках |
| **Изолир.** | Оставляет видимыми выбранные элементы, скрывая остальные |
| **Скрыть** | Скрывает выбранные элементы модели |

Подсчёт объёма, площади, длины и веса использует данные свойств модели. Для проверки расстояния или площади по указанным вручную точкам используйте [«Измерения»](/ru/signalbim/measurements).

Изоляция и скрытие меняют видимость элементов. Для возврата всех элементов используйте кнопку с открытым глазом на нижней панели.

#### Окно результата

- **«Итого»** — сумма и единица измерения. Кнопка рядом копирует результат.
- **«Рассчитано»** — сколько элементов содержат настроенное свойство относительно всего выделения.
- **«Не учтено»** — сколько элементов не содержат ни одного из настроенных свойств.
- **Круговые стрелки** — повторный расчёт по текущему выделению.

Если не все элементы учтены или итог неожиданен, проверьте названия свойств, их числовые значения, порядок и коэффициенты в настройках. Наличие свойства само по себе не гарантирует числовое значение: текст вместо числа даёт нулевой вклад в сумму.

### Настройки

#### Настройки {#calculation-settings}

#### Свойства, единицы и коэффициенты

1. Откройте **«Инструменты» → «Настройки»**.
2. Выберите вкладку нужного показателя.
3. Укажите единицу результата.
4. Кнопкой **«Добавить свойство»** добавьте свойства, из которых нужно брать значения. Для каждого задайте коэффициент.
5. Расположите свойства в порядке приоритета, перетаскивая строки за маркер слева.
6. Нажмите **«Сохранить»**.

Для каждого элемента используется **первое найденное свойство** из списка. Значения всех перечисленных свойств одного элемента не складываются. Если найденное свойство содержит текст вместо числа, следующее свойство не подставляется.

Коэффициент переводит исходное число в базовую единицу: **метры, квадратные метры, кубические метры или килограммы**. После суммирования приложение переводит результат в выбранную единицу отображения.

Например, если свойство длины содержит число в миллиметрах, коэффициент — **0,001**. Чтобы показать итог в миллиметрах, дополнительно выберите единицу **«Миллиметры»**.

Кнопка **«По умолчанию»** возвращает стандартный набор настроек и удаляет пользовательские типы подсчёта. При необходимости предварительно экспортируйте свои настройки.

#### Пользовательское свойство

Нажмите **«+»** рядом с вкладками. В окне **«Новое пользовательское свойство»** заполните **«Имя вкладки»** и **«Описание вкладки»**, затем нажмите **«Создать»**. На новой вкладке настройте единицу, свойства и коэффициенты, затем сохраните настройки.

Пользовательский тип можно переименовать кнопкой с карандашом и удалить кнопкой с корзиной. Стандартные типы удалить нельзя. Для запуска расчёта используйте кнопку **«Пользоват. свойство»** на ленте и выберите созданный тип.

#### Импорт и экспорт настроек

Кнопки импорта и экспорта в правой верхней части окна позволяют перенести настройки через файл. В качестве образца используйте экспорт из S BIM.

Поддерживается **`.xls` в формате XML (SpreadsheetML)**. Форматы `.xlsx` и обычный бинарный `.xls` не поддерживаются; смены расширения файла недостаточно.

Перед импортом загрузите модели: приложение проверяет наличие указанных свойств. После импорта прочитайте результат проверки — отдельные свойства или листы могли быть пропущены.
