### Инструменты

| Кнопка | Действие |
| --- | --- |
| **Объём** | Суммировать объём |
| **Площадь** | Суммировать площадь |
| **Длина** | Суммировать длину |
| **Кол-во** | Подсчитать выбранные элементы |
| **Вес** | Суммировать вес |
| **Пользоват. свойство** | Рассчитать пользовательский показатель |
| **Изолир.** | Оставить видимыми выбранные элементы |
| **Скрыть** | Скрыть выбранные элементы |

В окне результата показаны:

- **«Итого»** — сумма и единица измерения;
- **«Рассчитано»** — число элементов с настроенным свойством;
- **«Не учтено»** — число элементов без настроенных свойств.

![снимок_экрана_2026-11-13_155342.png](/снимок_экрана_2026-11-13_155342.png =500x)

Результат можно скопировать или пересчитать по новому выделению. Если итог неожиданен, проверьте свойства модели и настройки подсчёта.

### Настройки

![снимок_экрана_2026-11-13_155607.png](/снимок_экрана_2026-11-13_155607.png =500x)


#### Настроить показатель

1. Нажмите **«Настройки»** и выберите вкладку показателя.
2. Выберите единицу результата.
3. Добавьте свойства, задайте коэффициенты и расположите строки в порядке приоритета.
4. Нажмите **«Сохранить»**.

Для каждого элемента берётся **первое найденное свойство** из списка. Если оно содержит текст вместо числа, вклад в сумму будет нулевым; следующее свойство не подставляется.

#### Коэффициенты и единицы

Коэффициент переводит исходное число в базовые единицы:

- длина — **метры**;
- площадь — **квадратные метры**;
- объём — **кубические метры**;
- вес — **килограммы**.

После суммирования результат переводится в выбранную единицу отображения.

> **Пример:** если длина записана числом в миллиметрах, задайте коэффициент **0,001**. Для отображения итога в миллиметрах выберите единицу **«Миллиметры»**.
{.is-info}

#### Пользовательский показатель

- Нажмите **«+»**, задайте имя и описание, затем нажмите **«Создать»**.
- Настройте единицу, свойства и коэффициенты; сохраните изменения.
- Для расчёта нажмите **«Пользоват. свойство»** и выберите созданный показатель.

Пользовательские показатели можно переименовывать и удалять.

#### Перенос и сброс настроек

- Для переноса настроек используйте импорт и экспорт `.xls` 
- Перед импортом загрузите модели. После импорта проверьте сообщения о пропущенных свойствах или листах.

> **«По умолчанию»** восстанавливает стандартный набор и удаляет пользовательские показатели. Сохраните нужные настройки через экспорт до сброса.
{.is-warning}
