**Обозначения**
:fire: — новые возможности
:sparkles: — доработки функционала
:hammer_and_wrench: — исправление ошибок

----
**[2026.17](/general/updates/2026-17)** ^14.09.2026^

:sparkles: Доработали редактор графика Ганта: добавили полноценную клавиатурную навигацию, улучшили связь полей с календарём и интерфейс редактирования.

:sparkles: В SIGNAL Viewer добавили режим «Сечение по грани», последовательный выход из режимов клавишей <kbd>Esc</kbd> и ускоренную отрисовку среза. Скрытие и изолирование элементов больше не запускает полный пересчёт среза.

:sparkles: При обработке модели в Tangl передаётся существующее имя файла вместо идентификатора. Переименование в DOCS не меняет имя уже обработанной модели в Tangl.

----
**[2026.16](/general/updates/2026-16)** ^31.08.2026^

:fire: Добавили сравнение офисных файлов в Collabora: текущую версию можно сравнить с файлом, выбранным на устройстве.

:sparkles: Доработали SIGNAL Viewer для работы на узких экранах: панель инструментов разделена на группы, панели структуры, свойств и настроек можно менять по размеру, а элементы управления сохраняются видимыми при изменении окна и повороте устройства.

:hammer_and_wrench: Исправили центрирование PDF при перелистывании и сохранение XLSX с длинным названием.

----
**[2026.15](/general/updates/2026-15)** ^17.08.2026^

:fire: В SIGNAL Viewer добавили создание замечаний с привязкой к элементам модели и просмотр облаков точек Gaussian Splat PLY.

:hammer_and_wrench: Исправили размещение ручной подписи на iOS и её поворот в отдельных сценариях.

----
**[2026.14](/general/updates/2026-14)** ^03.08.2026^

:fire: SIGNAL Viewer получил поддержку форматов RVT, NWD и NWC. В сборках добавили поддержку FBX.

:sparkles: При просмотре сборки добавили обновление версий моделей.

----
**[2026.12](/general/updates/2026-12)** ^02.07.2026^

:fire: Добавили SIGNAL Viewer для просмотра BIM-моделей в форматах GLB и IFC.

----
**[2026.8](/general/updates/2026-8)** ^07.05.2026^

:fire: Реализовали ленту с предпросмотром всех файлов и создание и редактирование сборок по общим координатам и внутренним началам.

:sparkles: Добавили поиск по Id элемента для Navisworks в Forge и кнопку `Вернуться к общему виду` в сборках.

:hammer_and_wrench: Исправили калибровку линейки PDF, отображение имён файлов в обозревателе Forge и закрытие сборки при добавлении вложения в замечание.

----

:hammer_and_wrench: Исправили кнопку `Печать` в мобильной версии PDF-просмотрщика.

:hammer_and_wrench: Исправили настройки отображения при сравнении PDF и закрытие офисных документов в мобильной версии.
