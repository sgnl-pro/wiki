**[2026.17](/general/updates/2026-17)** ^14.09.2026^

:hammer_and_wrench: Исправили ошибку, из-за которой могло не завершаться копирование файлов с двумя атрибутами одного типа на этапе согласования.

----
**[2026.16](/general/updates/2026-16)** ^31.08.2026^

:hammer_and_wrench: Загрузку файла шаблона согласования сделали доступной администратору проекта; права администратора организации больше не требуются.

----
**[2026.15](/general/updates/2026-15)** ^17.08.2026^

:sparkles: Добавили настройку «Пользователь с доступом на создание может отменять процесс».

:sparkles: Расширили окно перезапуска согласования.

:hammer_and_wrench: Для полного перезапуска теперь нужен доступ на редактирование или разрешение отменять процесс для пользователей с доступом на создание.

:hammer_and_wrench: Вернули пользователям с доступом на редактирование возможность отменять завершённое согласование.

----
**[2026.13](/general/updates/2026-13)** ^20.07.2026^

:sparkles: При обновлении версий нескольких выбранных файлов актуальные версии пропускаются, а не блокируют действие целиком.

:sparkles: Добавили уведомление и запись в лог, когда ответственный открывает связанные с комплектом замечания. По умолчанию уведомление выключено в профиле пользователя.

----
**[2026.12](/general/updates/2026-12)** ^02.07.2026^

:sparkles: Пользователи с доступом на создание могут выбрать другой доступный тип при перезапуске согласования.

----

:fire: Добавили массовое редактирование и удаление типов согласования.

----

:sparkles: В окне добавления документов в комплект начали отображаться их статусы.

----
**[2026.8](/general/updates/2026-8)** ^07.05.2026^

:hammer_and_wrench: Исправили время отправки уведомлений об истечении срока согласований при завершении предыдущего этапа до 13:00.

:hammer_and_wrench: Исправили ошибку, при которой некоторые согласования отображались в статусе «Черновик» после перезапуска.

----
**[2026.7](/general/updates/2026-7)** ^23.04.2026^

:fire: Реализовали обновление файлов в процессе согласования.

:hammer_and_wrench: Починили отправку уведомления о том, что до конца согласования остался один день.

:hammer_and_wrench: Разблокировали кнопку `Отправить` при добавлении файлов в комплект из папки, когда на первом этапе согласования в качестве ответственного указано `Назначить в процессе`.

----
**[2026.6](/general/updates/2026-6)** ^09.04.2026^

:sparkles: Добавили отображение удаленных из согласования версий файлов.

:hammer_and_wrench: Добавили предупреждение об отсутствии активных ролей при запуске согласования из документов.

:hammer_and_wrench: Исправили некорректное отображение плановой и договорной даты в календаре согласований в некоторых случаях.

:hammer_and_wrench: Поправили сортировку в окне выбора файлов в согласовании.

:hammer_and_wrench: Исправили ошибку при перезапуске согласования у пользователей с правами на создание в случае, когда согласование было запущено администратором проекта.

:hammer_and_wrench: Отключили копирование списка пользователей или ролей при нажатии на этап согласования.

:hammer_and_wrench: Добавили игнорирование лишних пробелов при поиске.

**[2026.5](/general/updates/2026-5)** ^26.03.2026^

:sparkles: Для редакторов согласований добавили возможность менять плановую дату этапа из комплекта. Также добавили соответствующую опцию в настройки типа согласования, по умолчанию эта возможность отключена.

:sparkles: В настройки типа согласования также добавили поле `Наблюдатели` (пользователи и/или роли, которым должны приходить уведомления о начале, завершении и отклонении согласований этого типа) и вариант ответственного за этап `Назначить в процессе` — в этом случае ответственного выбирает пользователь, заверщающий предыдущий этап.

:sparkles: В комплект согласования при наведении на этап добавили список пользователей, за которыми закреплена роль (если в качестве ответственного в настройках выбрана роль, а не пользователь).

:sparkles: Добавили поле `Комментарий` при запуске согласования из документов.

:sparkles: Добавили дату загрузки последней версии файла при перезапуске согласования.

:hammer_and_wrench: Вывели в документах корректную дату аннулирования файла.

:hammer_and_wrench: Исправили некорректное отображение сроков в календаре согласований в случае, когда согласование этапа произошло после 13:00.
