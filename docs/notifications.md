В SIGNAL настройки уведомлений разделены между HUB и DOCS:

- в [профиле HUB](/hub/user#notifications) вы выбираете события, каналы доставки и способ объединения уведомлений;
- в DOCS вы включаете уведомления о событиях в папках для текущего проекта и управляете подписками на папки.

> Чтобы получать уведомления об изменениях в папке, включите событие **«Уведомлять о событиях в папках»** в профиле HUB, разрешите уведомления для текущего проекта в DOCS и подпишитесь на папку. Если хотя бы одна из этих настроек выключена, уведомления по подписке не придут.
{.is-info}

# Вкладки{.tabset}  
## 1. Настройки текущего проекта
### 1. Настройки текущего проекта {#project-settings}

Откройте меню учетной записи в правом верхнем углу, выберите **«Настройки»** и перейдите на вкладку **«Уведомления»**. Вкладка доступна всем пользователям проекта.

![2026-9-настройки_уведомлений-проект.png](/release_notes/2026-9-настройки_уведомлений-проект.png =900x)

Здесь можно:

- включить или выключить **«Уведомления о событиях в папках»** для текущего проекта;
- найти папку по названию;
- просмотреть личные подписки и подписки, назначенные вашей роли;
- перейти в подписанную папку;
- удалить личную подписку.

Выключение уведомлений для проекта не удаляет подписки. После повторного включения список подписанных папок сохранится.

> Эта настройка относится только к событиям в подписанных папках текущего проекта. Уведомления о замечаниях, согласованиях и передачах настраиваются в [профиле HUB](/hub/user#notifications).
{.is-info}

## 2. Личные подписки
### 2. Личные подписки {#personal-subscriptions}

Чтобы подписаться на обновления папки:

1. Откройте контекстное меню папки.
2. Выберите **«Подписаться на обновления»**.
3. Подтвердите подписку.

Команда доступна, если у вас есть право на чтение папки. Подписка действует и для вложенных папок. Если вы уже подписаны на родительскую папку, создать отдельную подписку на дочернюю папку нельзя — в окне будет указана родительская папка.

Чтобы отписаться, снова выберите **«Подписаться на обновления»** в контекстном меню папки либо удалите подписку на вкладке **«Настройки» → «Уведомления»**.

## 3. Подписки ролей
### 3. Подписки ролей {#role-subscriptions}

Администратор проекта может подписать на папку одну или несколько ролей. Для этого:

1. Откройте контекстное меню папки.
2. Выберите **«Настроить подписки»**.
3. Добавьте роли и закройте окно.

Участники выбранных ролей, у которых есть право на чтение папки, увидят такие подписки в разделе **«По ролям»** на вкладке **«Настройки» → «Уведомления»**. Удалить подписку роли можно через команду **«Настроить подписки»** в контекстном меню папки.
