**Обозначения**

----
**[2026.16](/general/updates/2026-16)** ^31.08.2026^

:hammer_and_wrench: Отключили отправку уведомлений по удалённым замечаниям.

:hammer_and_wrench: В уведомления о замечаниях комплекта больше не включаются файлы, которых нет в комплекте.

:hammer_and_wrench: Исправили пример шаблона предписания для атрибутов, в названии которых есть пробелы.

----
**[2026.15](/general/updates/2026-15)** ^17.08.2026^

:fire: Добавили создание замечаний в SIGNAL Viewer с привязкой выбранных элементов модели. При открытии замечания связанные элементы изолируются, а камера фокусируется на них.

:hammer_and_wrench: Исправили открытие ранее выбранного файла при добавлении замечания из комплекта согласования.

----
**[2026.12](/general/updates/2026-12)** ^02.07.2026^

:fire: Добавили генерацию файлов предписаний DOCX из карточек замечаний по шаблонам типов замечаний.

----
**[2026.11](/general/updates/2026-11)** ^18.06.2026^

:sparkles: Убрали панель навигации файла при открытой карточке замечания.

:hammer_and_wrench: Исправили отображение интерфейса при заполнении текстовой пометки.

----
**[2026.10](/general/updates/2026-10)** ^04.06.2026^

:hammer_and_wrench: Исправили дублирование идентификаторов элементов моделей Navisworks, мешавшее привязывать элементы к замечаниям.

----
**[2026.9](/general/updates/2026-9)** ^21.05.2026^

:sparkles: Добавили подсказку о вставке изображений из буфера обмена при добавлении вложения.

:hammer_and_wrench: Исправили отображение ролей в комментариях PDF-отчёта по замечаниям.

----
**[2026.8](/general/updates/2026-8)** ^07.05.2026^
  
:hammer_and_wrench: Поправили форматирование отчёта замечаний в PDF при длинном описании, а также формирование отчёта с большим количеством замечаний.
  
----
**[2026.7](/general/updates/2026-7)** ^23.04.2026^
  
:sparkles: Оптимизировали экспорт большого количества замечаний в PDF, в том числе с графическими вложениями.
  
:hammer_and_wrench: Вернули предупреждение при изменении типа у замечания, если хотя бы один заполненный атрибут будет удален.
  
:hammer_and_wrench: Вернули автоподстановку значений атрибутов из папок и файлов при создании замечания.
  
----
**[2026.6](/general/updates/2026-6)** ^09.04.2026^
  
:sparkles: Добавили возможность скачать вложения из карточки замечания архивом.
  
:sparkles: Реализовали сохранение значений одинаковых атрибутов при смене типов замечаний.
  
:hammer_and_wrench: Добавили игнорирование лишних пробелов при поиске.
  
----
**[2026.5](/general/updates/2026-5)** ^26.03.2026^
  
:sparkles: В замечаниях в сборках теперь доступны функции прикрепления элементов и пометки.
  
:hammer_and_wrench: Вернули возможность автору замечания менять его тип, выбирая среди доступных.
   
----
**[2026.3](/general/updates/2026-3)** ^03.03.2026^
  
:sparkles: Добавили возможность выделять элементы в таблицах и списках с помощью <kbd>Shift</kbd>.
  
:sparkles: Сделали так, чтобы высота шрифта и выравнивание текста сохранялись при создании следующей пометки.
  
:sparkles: Добавили возможность отображать графические вложения при экспорте замечаний в PDF.
  
:sparkles: Добавили фильтрацию по дате устранения в замечаниях.
  
:hammer_and_wrench: Устранили ошибку при открытии замечания, если в названии роли был символ `+`.
  
----
**[2026.2](/general/updates/2026-2)** ^12.02.2026^
  
:sparkles: В управление видимостью и положением столбцов в таблицах добавили пользовательские атрибуты.
  
:sparkles: Добавили подсказки о ролях пользователей и о пользователях, к которым относится роль, в выпадающих списках.
  
:sparkles: При создании пометок теперь выбирается последний используемый инструмент.
  
:sparkles: В настройках типа замечания добавили необязательное поле для выбора пользователей или ролей, которые станут наблюдателями замечаний по умолчанию.
