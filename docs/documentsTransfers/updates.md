> Здесь перечислены основные изменения. Для получения подробностей нажмите на номер версии.
{.is-info}

**Обозначения**
:fire: — новые возможности
:sparkles: — доработки функционала
:hammer_and_wrench: — исправление ошибок

----
**[2026.14](/general/updates/2026-14)** ^03.08.2026^

:fire: Добавили копирование передачи. В новую передачу подставляются параметры и неудалённые файлы выбранного пакета; перед созданием их можно изменить.

----
**[2026.13](/general/updates/2026-13)** ^20.07.2026^

:sparkles: В настройках типа передачи добавили значения по умолчанию для списка оповещаемых, отправителя, получателя, номера договора и названия проекта.

----
**[2026.11](/general/updates/2026-11)** ^18.06.2026^

:sparkles: Разрешили использовать символы `< > : " / \ | ? *` в шифре передачи.

----
**[2026.10](/general/updates/2026-10)** ^04.06.2026^

:sparkles: Добавили формирование акта передачи сразу из комплекта согласования.

:sparkles: В публичный реестр передач добавили столбцы `Дата создания` и `Автор`.

:hammer_and_wrench: Починили просмотр офисных документов из пакетов передачи.

----
**[2026.9](/general/updates/2026-9)** ^21.05.2026^

:fire: В настройках типа передачи добавили необязательный дополнительный текст, который выводится в конце акта.

:sparkles: При создании пакета из комплекта согласования начали автоматически подставляться шифр и название.

:hammer_and_wrench: Исправили формирование акта с большим количеством документов.

----
**[2026.8](/general/updates/2026-8)** ^07.05.2026^

:fire: При просмотре файла из передачи добавили ленту предпросмотра и переключение между соседними файлами пакета.

----
**[2026.7](/general/updates/2026-7)** ^23.04.2026^

:sparkles: В реестр передач добавили столбцы `Дата создания` и `Автор`.

----
**[2026.6](/general/updates/2026-6)** ^09.04.2026^

:sparkles: Добавили версии файлов с датами их создания в акт передачи.

:hammer_and_wrench: После добавления файлов в пакет из документов окно больше не закрывается, чтобы можно было перейти в пакет. Уже запущенные пакеты скрыты из этого окна.

:hammer_and_wrench: Добавили игнорирование лишних пробелов при поиске.

----
**[2026.3](/general/updates/2026-3)** ^03.03.2026^

:sparkles: Добавили возможность выделять элементы в таблицах и списках с помощью <kbd>Shift</kbd>.

:sparkles: Вывели в документах статус передачи с информацией и переходом к пакету.

:sparkles: Добавили кнопку `Открыть передачу` в окно добавления файлов в пакет.

----
**[2026.2](/general/updates/2026-2)** ^12.02.2026^

:sparkles: В управление видимостью и положением столбцов в таблицах добавили пользовательские атрибуты.

:sparkles: Добавили подсказки о ролях пользователей и о пользователях, к которым относится роль, в выпадающих списках.

----
**[2026.1](/general/updates/2026-1)** ^22.01.2026^

:fire: Реализовали управление видимостью и положением столбцов в таблице.

:sparkles: Добавили обязательное поле `Название проекта` при формировании акта передачи. По умолчанию подставляется название текущего проекта, но его можно изменить.

----
**[2025.41](/general/updates/2025-41)** ^25.12.2025^

:sparkles: Добавили просмотр файлов PDF для всех пользователей, у которых есть доступ к пакету.

----
**[2025.38](/general/updates/2025-38)** ^04.12.2025^

:fire: Реализовали публикацию акта передачи для подписания сторонним лицом без доступа к системе или проекту. Публичная ссылка настраивается на уровне типа передачи.

----
**[2025.34](/general/updates/2025-34)** ^06.11.2025^

:sparkles: Добавили в реестр передач столбцы `Компания-отправитель` и `Компания-получатель`.

----
**[2025.32](/general/updates/2025-32)** ^23.10.2025^

:sparkles: Добавили необязательное поле `Оповестить` при создании пакета передачи.

----
**[2025.31](/general/updates/2025-31)** ^16.10.2025^

:sparkles: Добавили быстрые фильтры по типу передачи в реестре.

----
**[2025.30](/general/updates/2025-30)** ^09.10.2025^

:sparkles: При создании пакета передачи из согласования в него добавляются только выбранные файлы.

:sparkles: Реализовали поиск по роли в списках выбора пользователей и ролей.

:hammer_and_wrench: Исправили отображение подписей в некоторых сценариях.

----
**[2025.29](/general/updates/2025-29)** ^03.10.2025^

:hammer_and_wrench: Исправили ошибку, из-за которой после обновления страницы не отображался выбранный пользователь в поле `Получатель` в настройках типа передачи.

> Информация о более ранних обновлениях доступна в закрытом Telegram-канале для пользователей SIGNAL. Для добавления [обратитесь в поддержку](/general/support).
