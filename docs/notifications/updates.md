**[2026.16](/general/updates/2026-16)** ^31.08.2026^

:fire: В [профиле пользователя](/hub/user#notifications) добавили получение уведомлений SIGNAL в MAX. Общие настройки каналов применяются к отдельным событиям по умолчанию.

----
**[2026.13](/general/updates/2026-13)** ^20.07.2026^

:sparkles: Добавили уведомление об открытии комплекта согласования ответственным за связанные замечания. Этот тип уведомления по умолчанию выключен и включается в профиле пользователя.

----
**[2026.9](/general/updates/2026-9)** ^21.05.2026^

:fire: Расширенные настройки событий, каналов и объединения уведомлений перенесли в [профиль HUB](/hub/user#notifications). В DOCS оставили включение уведомлений для текущего проекта и управление подписками на папки.
