**[SIGNAL DOCS](https://docs.sgnl.pro/)** — среда общих данных для хранения, просмотра и передачи инженерной документации проекта. В DOCS можно работать с версиями файлов, BIM-моделями, замечаниями и согласованиями.

Откройте DOCS в браузере. Для работы с файлами на компьютере используйте [DOCS Disk](/docs/disk), а для доступа с устройства Android — [мобильное приложение](/docs/more#Android). Доступные проекты и действия зависят от вашей роли и прав на папки.

> Для проекта можно выбрать системное S3-хранилище SIGNAL или подключённое хранилище компании. Назначение хранилища настраивается в [HUB](/hub/admin#s3server).
