**Обозначения**
:fire: — новые возможности
:sparkles: — доработки функционала
:hammer_and_wrench: — исправление ошибок

----
**[2026.16](/general/updates/2026-16)** ^31.08.2026^

:fire: Добавили копирование структуры папок вместе с файлами и всей историей их версий. Копирование с файлами доступно между проектами одной компании, использующими одно S3-хранилище.

:fire: Добавили загрузку папок с компьютера, включая пустые вложенные папки.

:sparkles: В подсказке значка обработки модели отображаются статус, дата и время конвертации для Tangl Viewer, Autodesk Forge и SIGNAL Viewer.

:sparkles: В уведомлении о загрузке файлов появилась ссылка на целевую папку.

:hammer_and_wrench: Увеличили ограничение вложенности папок до 16 уровней при загрузке папки с устройства.

----
**[2026.15](/general/updates/2026-15)** ^17.08.2026^

:fire: В масках наименований файлов можно использовать атрибуты типов `Текст`, `Дата` и `Список`.

----
**[2026.13](/general/updates/2026-13)** ^20.07.2026^

:sparkles: В окно загрузки файлов добавили получателей уведомления и комментарий к версии. Значения можно заполнить сразу для нескольких файлов.

:sparkles: Доработали копирование и перемещение файлов в папки с масками.

:sparkles: Добавили подсвечивание файла в папке при его закрытии.

:hammer_and_wrench: Исправили загрузку файлов с скрытыми символами.

:hammer_and_wrench: Устранили ошибку при назначении атрибута через контекстное меню.
