**SIGNAL DOCS Disk** — приложение для Windows, с помощью которого можно работать с файлами SIGNAL DOCS в проводнике и установленных на компьютере программах. Вы выбираете файлы и папки для синхронизации, получаете их из DOCS, редактируете локальные копии и отправляете изменения обратно как новые версии.

> DOCS Disk синхронизирует только выбранные файлы и папки. Включение синхронизации само по себе не скачивает файлы: после него нажмите **«Получить»**.
{.is-info}

# Вкладки {.tabset}
## 1. Установка и вход
###### 1. Установка и вход {#started}

1. Откройте [hub.sgnl.pro](https://hub.sgnl.pro/), перейдите в раздел **«Модули»** и скачайте DOCS Disk.
2. Запустите установочный файл `.exe` и установите приложение.

![](/chrome_zgzhfmtsry.png =70%x)

3. Запустите DOCS Disk и нажмите **«Войти»**.

![](/signal_docs_disk_pt48hruxuz.png =70%x)

4. Авторизуйтесь с учётной записью SIGNAL. После входа выберите компанию и проект.

## 2. Настройка папки хранения
###### 2. Настройка папки хранения {#settings}

Перед первой синхронизацией укажите папку, в которой DOCS Disk будет хранить локальные копии файлов:

1. Откройте меню учётной записи и выберите **«Настройки»**. До входа настройки можно открыть кнопкой с шестерёнкой на экране авторизации.
2. На вкладке **«Сервер»** в поле **«Директория хранения файлов»** выберите локальную папку.
3. Сохраните изменение. Приложение автоматически перезапустится.

![](/signal_docs_disk_xgybkovvyy.png =70%x)

![](/signal_docs_disk_ofnzi2aj7v.png =70%x)

В выбранной директории приложение создаёт папки компании и проекта, а внутри воспроизводит синхронизированную структуру DOCS.

## 3. Интерфейс
###### 3. Интерфейс {#interface}

DOCS Disk показывает раздел документов выбранного проекта. Доступные действия зависят от ваших прав в папках.

1. Дерево папок проекта.
2. Содержимое открытой папки.
3. Поиск по текущей папке и фильтры по дате изменения и формату файла. Поиск начинается после ввода не менее двух символов.
4. Кнопка **«Получить»** — скачать новые и обновлённые версии синхронизируемых файлов из DOCS.
5. Кнопка **«Отправить»** — загрузить локальные изменения и новые локальные файлы в DOCS.
6. Статус операций. Нажмите на него, чтобы открыть список задач, посмотреть ошибки и конфликты, повторить операцию или разрешить конфликт.

![](/signal_docs_disk_hpcuhmvnzl.png =70%x)

Кнопка **«+»** позволяет загрузить в открытую папку файл, папку или ссылку. Папки также можно создавать, переименовывать, перемещать и удалять — если у вас есть соответствующие права.

## 4. Синхронизация
###### 4. Синхронизация {#sync}

### Включение и отключение синхронизации

1. Выделите один или несколько файлов и папок. Ссылки синхронизировать нельзя.
2. Нажмите кнопку **«Включить синхронизацию»** на панели действий. Для одного объекта действие также доступно в контекстном меню по правой кнопке мыши.
3. Нажмите **«Получить»** в верхней части окна. DOCS Disk создаст выбранные папки и скачает файлы в настроенную директорию.

![](/signal_docs_disk_pnoz9f42td.png =70%x)

Чтобы перестать отслеживать выбранные объекты, используйте действие **«Отключить синхронизацию»**. Локальные копии при этом не удаляются.

### Работа с локальными файлами

Чтобы открыть папку синхронизированного файла в проводнике, нажмите на файл правой кнопкой мыши и выберите **«Открыть расположение файла»**. Для папки используйте действие **«Расположение папки»**.

![](/signal_docs_disk_hq8kpo9cef.png =70%x)

![](/signal_docs_disk_ey0y7nzx5e.png =70%x)

Дважды нажмите на файл в DOCS Disk, чтобы скачать его при необходимости и открыть в программе, назначенной для этого формата в Windows.

После редактирования сохраните файл в той же локальной папке.

![](/winword_2unhcujsni.png =70%x)

DOCS Disk отметит изменённый файл. Нажмите **«Отправить»**, чтобы загрузить изменения в DOCS как новую версию.

![](/lgbslepwya.png =70%x)

![](/signal_docs_disk_2lpy7w425r.png =70%x)

Если вы добавили новый файл в синхронизируемую папку на компьютере, кнопка **«Отправить»** создаст такой же файл в соответствующей папке DOCS. Если в DOCS уже есть файл с тем же именем, приложение зафиксирует конфликт и не заменит его автоматически.

### Конфликты и ошибки

Перед получением DOCS Disk проверяет, нет ли несохранённых локальных изменений. Перед отправкой — не появилась ли в DOCS более новая версия. В таких случаях операция получает статус **«Конфликт»**.

Нажмите на индикатор задач в верхней части окна, откройте конфликт и выберите **«Разрешить»**. Приложение предложит подтвердить замену локального файла или обновление версии в DOCS. Ошибочную задачу можно повторить или удалить из списка; выполняющуюся задачу — отменить.

### Удаление локальных копий

Чтобы освободить место на компьютере, нажмите на файл или папку правой кнопкой мыши и выберите **«Хранить в облаке»**.

![](/signal_docs_disk_tcux4l3ljf.png =70%x)

Действие удаляет локальные копии, но не удаляет файлы из DOCS и не отправляет локальные изменения. Перед его выполнением нажмите **«Отправить»** и дождитесь завершения операций, иначе несохранённые в DOCS изменения будут потеряны.

## 5. Параметры приложения
###### 5. Параметры приложения {#userSettings}

В меню учётной записи выберите **«Настройки»** и откройте вкладку **«Параметры приложения»**.

![](/signal_docs_disk_jzcqvr3r79.png =70%x)

По умолчанию при конфликте DOCS Disk запрашивает подтверждение перезаписи. Переключатели позволяют пропускать это подтверждение:

- **«Принудительно перезаписывать файлы в DOCS при Отправке»** — при разрешении конфликта получения заменяет изменённую локальную копию версией из DOCS без дополнительного подтверждения.
- **«Принудительно перезаписывать локальные файлы при Получении»** — при разрешении конфликта отправки загружает локальный файл в DOCS как новую версию без дополнительного подтверждения.

> Названия этих двух параметров в текущей версии приложения не соответствуют выполняемым действиям. В списке выше указано их фактическое поведение.
