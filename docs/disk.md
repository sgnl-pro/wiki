**SIGNAL DOCS Disk** — приложение для Windows, которое показывает проекты, папки и файлы DOCS прямо в Проводнике. Открывайте файлы в установленных программах, редактируйте и сохраняйте их: изменения автоматически отправляются в DOCS как новые версии. Изменения коллег также появляются на вашем компьютере.

> Новое приложение находится на **расширенном бета-тестировании**. Публикация для всех пользователей запланирована в релизе **2026.20**.
{.is-info}

Прежний DOCS Disk с командами «Получить» и «Отправить» остаётся доступен. Его инструкция перенесена в [«DOCS. Дополнительно» → «DOCS Disk — прежняя версия»](/docs/more#legacy-disk).

# Вкладки {.tabset}
## 1. Установка и вход
###### 1. Установка и вход {#started}

Приложение поддерживает **Windows 10 и Windows 11**. Для установки нужны права администратора. Все необходимые компоненты, включая .NET, входят в установщик.

1. Откройте [HUB](https://hub.sgnl.pro/), перейдите в раздел **«Модули»** и скачайте новый DOCS Disk. Установщик нового приложения — файл `.msi`.
2. Запустите `.msi`, разрешите установку от имени администратора и следуйте шагам мастера.
3. Если вы используете DOCS на собственном сервере (**on-premise**), укажите адрес сервера. Без него установка этой версии невозможна. Адрес можно уточнить у администратора вашей компании.
4. Запустите DOCS Disk и нажмите **«Войти»**. Авторизация откроется в вашем обычном браузере. Можно использовать сохранённые пароли, ключи доступа и корпоративный вход.
5. Когда в браузере появится сообщение **«Вход выполнен»**, закройте вкладку и вернитесь в приложение.
6. Выберите компанию. В Проводнике появятся её проекты, к которым у вас есть доступ. Одновременно приложение показывает проекты одной компании.

<span style="color: red;">[Добавить скриншот: главное окно нового DOCS Disk после входа, выбор компании и настройка буквы диска.]</span>

Приложение работает в системном трее рядом с часами. Дважды нажмите на его значок, чтобы открыть главное окно; нажмите правой кнопкой мыши, чтобы открыть меню.

Облачную и on-premise версии можно установить рядом. Язык интерфейса — русский или английский — выбирается по языку Windows.

### Обновление и переустановка

Запустите более новый `.msi`, чтобы обновить установленное приложение. Повторный запуск того же пакета позволяет выбрать **«Переустановить»** для восстановления установки или **«Удалить»**.

Для on-premise смена адреса сервера потребует повторного входа. Если приложение сообщает, что адрес сервера не задан, переустановите его и укажите адрес.

## 2. Папка и буква диска
###### 2. Папка и буква диска {#settings}

Файлы находятся в папке **SIGNAL DOCS** в вашем профиле Windows. Для on-premise в имени также указан сервер: `SIGNAL DOCS (<сервер>)`.

В Проводнике папка отображается в разделе **«Этот компьютер»**, рядом с дисками. Внутри находятся проекты выбранной компании, а в каждом проекте — его папки и файлы из DOCS.

### Буква диска

Если программе или настройкам проекта нужна буква диска, включите её в главном окне DOCS Disk и выберите букву, например `S:`.

- Пока буква включена, отдельная папка SIGNAL DOCS скрывается из раздела «Этот компьютер». При отключении буквы папка возвращается. Файлы остаются на прежнем месте.
- Диск доступен, пока работает приложение. После закрытия DOCS Disk буква исчезает, после запуска появляется снова.
- Программы, запущенные **от имени администратора**, не видят эту букву диска.
- Показатель свободного места соответствует системному диску компьютера.

### Длинные пути

Чтобы программы могли открывать файлы глубоко в структуре проекта, приложение использует короткие имена для вложенных папок. В Проводнике при этом отображаются полные имена из DOCS, а в окнах открытия и сохранения программ может быть видно короткое имя.

Открывайте файлы двойным щелчком в Проводнике. Переименование такой папки меняет её имя в DOCS. Короткие имена одинаковы на разных компьютерах, что позволяет сохранять ссылки между файлами.

## 3. Работа с файлами
###### 3. Работа с файлами {#interface}

Работайте с файлами внутри проекта, как с обычными файлами на компьютере. Действия выполняются с учётом [прав доступа](#permissions).

| Действие на компьютере | Результат в DOCS |
| --- | --- |
| Создать или скопировать новый файл либо папку в проект | Объект автоматически создаётся в соответствующей папке DOCS. |
| Отредактировать и сохранить файл | Появляется новая версия того же файла. |
| Переименовать файл или папку | Имя меняется в DOCS. |
| Переместить файл или папку внутри проекта | Объект перемещается в DOCS. Перед перемещением папки приложение запрашивает подтверждение. |

Сохранения из Word, Excel, Revit, Navisworks и AutoCAD обрабатываются как новые версии файла, в том числе если программа использует временные файлы. Служебные файлы, например блокировки Office `~$…`, резервные копии AutoCAD `.bak` и файлы `.dwl`, в DOCS не выгружаются.

Новый файл размером **до 10 байт включительно** отправляется в DOCS после сохранения содержимого, когда его размер превысит 10 байт.

Создавайте файлы и папки **внутри проекта**: в корне SIGNAL DOCS рядом с проектами это запрещено. Проекты нельзя удалить, переименовать или переместить через Проводник. Удалённая папка проекта восстанавливается. При превышении допустимой глубины вложенности приложение не даст создать или переместить папку и покажет предупреждение.

### Удаление

> Удаление файла или папки из SIGNAL DOCS, в том числе в Корзину Windows, **удаляет объект в DOCS у всех участников проекта**. Перемещение за пределы SIGNAL DOCS также удаляет объект в DOCS. Приложение запрашивает подтверждение. Восстановление из Корзины Windows не отменяет удаление в DOCS.
{.is-warning}

Чтобы удалить только скачанную копию с компьютера, используйте **«Освободить место»**. Подробнее — в разделе [«Синхронизация и офлайн-доступ»](#sync).

### Контекстное меню и ссылки

Нажмите на файл или папку правой кнопкой мыши и откройте подменю **SIGNAL DOCS**. В Windows 11 сначала выберите **«Показать дополнительные параметры»** или нажмите `Shift+F10`.

| Команда | Что делает |
| --- | --- |
| **«Открыть в DOCS»** | Открывает файл или папку в веб-версии DOCS. |
| **«Копировать ссылку»** | Копирует ссылку на файл или папку в веб-версии DOCS. |
| **«Копировать ссылку для Проводника»** | Копирует ссылку, которую коллега может вставить в адресную строку Проводника. Откроется та же папка; если ссылка на файл, он будет выделен. |
| **«Всегда сохранять на этом устройстве»** | Скачивает файл или папку для работы без интернета. |
| **«Освободить место»** | Удаляет скачанную копию с компьютера, сохраняя файл в DOCS. |

Для ссылки Проводника у коллеги должно работать приложение DOCS Disk, быть выбрана та же компания и быть доступ к папке. Если ссылка относится к другой компании, сначала переключите компанию в приложении.

## 4. Синхронизация и офлайн-доступ
###### 4. Синхронизация и офлайн-доступ {#sync}

### Файлы по требованию

DOCS Disk не скачивает все файлы заранее. До первого открытия на компьютере хранится только информация о файле, которая почти не занимает места. При открытии содержимое скачивается автоматически; для больших файлов Проводник показывает ход загрузки.

Чтобы подготовить файлы к работе без интернета:

1. Подключитесь к интернету.
2. Выберите нужный файл или папку, откройте контекстное меню и нажмите **«Всегда сохранять на этом устройстве»**.
3. Дождитесь завершения скачивания. После этого файлы будут доступны без интернета. Новые файлы в выбранной папке также будут скачиваться при наличии связи.

Для освобождения места выберите **«Освободить место»**. Файл останется в DOCS и снова скачается при следующем открытии. Контроль памяти Windows также может освобождать место от давно не открывавшихся файлов; файлы с отметкой «Всегда сохранять на этом устройстве» он не затрагивает.

Поиск Windows и программы-сканеры не скачивают автоматически всё содержимое папки SIGNAL DOCS.

### Состояния и сведения о файле

| Значок в столбце «Состояние» | Значение |
| --- | --- |
| Облако | Файл находится только в DOCS. Для открытия нужна связь с сервером. |
| Зелёная галочка | Файл скачан и соответствует версии в DOCS. |
| Стрелки | Идёт синхронизация изменений. |

В Проводнике можно дополнительно включить столбцы **«Версия»** — номер версии в DOCS — и **«Кем изменен»** — автор последней версии.

<span style="color: red;">[Добавить скриншот: файлы проекта в Проводнике со столбцами «Состояние», «Версия» и «Кем изменен».]</span>

### Изменения коллег и конфликты

Новые файлы, версии, переименования, удаления и изменения прав из DOCS появляются автоматически, без перезапуска приложения. После восстановления связи приложение получает пропущенные изменения.

Если коллега обновил файл, который у вас открыт в программе, применение обновления откладывается до закрытия файла. Если файл заблокирован в DOCS, ваши сохранённые изменения остаются на компьютере со значком синхронизации и отправляются после снятия блокировки.

Если в DOCS появилась новая версия, пока у вас были неотправленные правки, приложение сохраняет вашу версию и отправляет её как самую новую. Версия коллеги остаётся в истории файла в DOCS. Приложение сообщает о конфликте.

## 5. Права и восстановление
###### 5. Права и восстановление {#permissions}

DOCS Disk соблюдает права доступа к каждой папке DOCS.

| Если нет права | Поведение приложения |
| --- | --- |
| **Просмотр** | Вместо содержимого папки отображается файл «Нет доступа к этой папке.txt» с пояснением. Он существует только на компьютере и исчезает после выдачи доступа. |
| **Скачивание** | Файл виден, но не открывается. Приложение сообщает о запрете скачивания. |
| **Добавление** | Windows отклоняет копирование, перемещение или создание файла в папке. Исходный файл остаётся на месте. |
| **Изменение** | Файл доступен только для чтения. Если программа всё же сохранит правки, после закрытия файла приложение вернёт версию из DOCS, а правки сохранит в «Восстановленных файлах». |
| **Удаление** | Удаление отменяется, приложение показывает предупреждение. |
| **Переименование или перемещение** | Исходное имя восстанавливается, приложение показывает предупреждение. |

Если вы можете добавлять файлы, но не можете просматривать их, новый файл загрузится в DOCS и исчезнет из папки на компьютере. Приложение предупредит об этом. Уведомление также появится при изменении ваших прав на папку.

### Если отозван доступ к проекту

Приложение сообщает об отзыве доступа и убирает файлы, которые были только в DOCS. Скачанные копии остаются в папке проекта как обычные файлы. Если скачанных файлов нет, папка проекта удаляется с компьютера. Отправлять изменения в этот проект больше нельзя.

### Восстановленные файлы {#recovered}

Если локальный файл с неотправленными изменениями приходится убрать из папки проекта, приложение переносит его в **«Восстановленные файлы»**. Например, это происходит при удалении файла на сервере, запрете создания или редактирования либо смене компании во время работы в приложении. При такой смене компании туда также переносятся ваши локальные файлы, которых ещё нет в DOCS.

Путь к файлам:

`<профиль>\SIGNAL DOCS - Восстановленные файлы\<дата>\<проект>\<папки>\<файл>`

Ссылка на папку и её размер появляются в левом нижнем углу главного окна. Откройте папку и проверьте сохранённые файлы. Это отдельная папка, а не Корзина Windows; Windows не очищает её автоматически.

Кнопка **«Очистить»** безвозвратно удаляет восстановленные файлы после подтверждения. Перед очисткой сохраните всё, что вам нужно.

> При смене компании **после выхода из учётной записи** действует другой порядок: папки прежней компании отправляются в Корзину Windows. Подробнее — в разделе [«Настройки и выход»](#userSettings).
{.is-warning}

## 6. Настройки и выход
###### 6. Настройки и выход {#userSettings}

### Смена компании и пользователя

Выберите другую компанию в главном окне. Приложение заменит содержимое папки проектами новой компании. Файлы прежней компании останутся в DOCS, а их копии будут убраны с компьютера. Неотправленные изменения и локальные файлы, которых нет в DOCS, переместятся в [«Восстановленные файлы»](#recovered). Если такой файл открыт в программе, папка его проекта останется на месте.

Чтобы выйти из учётной записи, нажмите **«Выйти»**. Папка отключится от DOCS: файлы, которые были только в DOCS, исчезнут с компьютера, а скачанные останутся как обычные файлы. При следующем входе потребуется повторная авторизация. Вход под другой учётной записью также меняет доступное содержимое.

> **Перед выходом дождитесь окончания синхронизации.** Если после выхода войти и выбрать другую компанию, приложение уже не сможет отличить скачанные копии от ваших локальных файлов и отправит папки прежней компании целиком в Корзину Windows. Если Корзина их не принимает, папки останутся на месте; при этом слишком большие для Корзины файлы Windows может удалить сразу.
{.is-warning}

### Автозапуск и остановка

Включите **«Автозапуск»** в главном окне, чтобы DOCS Disk запускался при входе в Windows.

Чтобы завершить работу приложения, нажмите на его значок в трее правой кнопкой мыши и выберите **«Закрыть и остановить синхронизацию»**. Папка останется в Проводнике, но файлы, которые не скачаны, не откроются, а локальные изменения не отправятся до следующего запуска. Если включена буква диска, она исчезнет до запуска приложения.

### Удаление приложения

Удалите DOCS Disk через **«Параметры» → «Приложения»** Windows или повторно запустите `.msi` и выберите **«Удалить»**. Папка SIGNAL DOCS со скачанными файлами останется на компьютере. При необходимости удалите её вручную, предварительно сохранив нужные локальные данные.

### Установка для организации

Администратор может установить тот же `.msi` без диалогов через `msiexec` с параметром `/qn` или распространить его через групповую политику. Установщик позволяет задать начальные настройки:

| Свойство | Назначение |
| --- | --- |
| `HUB` | Адрес собственного сервера DOCS для on-premise. Для групповой политики задаётся через MST. |
| `AUTORUN` | Автозапуск приложения. |
| `DRIVELETTER` | Буква диска. |
| `COMPANY` | Компания по умолчанию. |

Пользователь может изменить начальные настройки в приложении. При смене адреса сервера потребуется войти заново.

## 7. Решение проблем
###### 7. Решение проблем {#troubleshooting}

| Ситуация | Что делать |
| --- | --- |
| **Сервер недоступен**, в главном окне красная полоса | Скачанные файлы остаются доступны, а файлы только в DOCS открыть нельзя. Нажмите **«Проверить доступность»**. При восстановлении связи работа возобновится автоматически. Папка, открытая при плохой связи, может ненадолго выглядеть пустой. |
| **Синхронизация приостановлена сервером**, жёлтая полоса | Дождитесь возобновления. Новые файлы не скачиваются и не отправляются, но скачанные доступны. Локальные изменения сохраняются и отправятся после возобновления. |
| **Версия больше не поддерживается** | Приложение покажет минимальную поддерживаемую версию и закроется. Установите новую версию DOCS Disk. |
| **Сессия истекла** | Войдите в учётную запись повторно по запросу приложения. |
| Перестали приходить изменения в реальном времени | Приложение сообщит об этом. Изменения загрузятся при открытии папки; для восстановления обновлений в реальном времени перезапустите DOCS Disk. |
| Папка SIGNAL DOCS видна в разделе «Этот компьютер», но не открывается и отсутствует в левой панели | Откройте Диспетчер задач, выберите **«Проводник» → «Перезапустить»** либо выйдите из Windows и войдите снова. |
| После обновления у пунктов контекстного меню нет значков | Перезапустите Проводник либо выйдите из Windows и войдите снова. |

Подробный журнал операций доступен в главном окне DOCS Disk. При обращении в [поддержку SIGNAL](/general/support) откройте папку с журналами кнопкой в этом окне и приложите нужные файлы к обращению.
