# Вкладки {.tabset}
## 1. Добавление файлов
### 1. Добавление файлов {#addingFiles}
### Вкладки {.tabset}

#### 1.1. Загрузка файлов и папок
###### 1.1. Загрузка файлов и папок {#uploadings}

Загружать содержимое можно несколькими способами:

1. Перетащите файлы или папку из проводника в область **Документы**.
2. В нужной папке нажмите `+` → `Загрузить файл`, выберите файлы и подтвердите загрузку.
3. Чтобы перенести структуру с компьютера, в том числе пустые вложенные папки, нажмите `+` → `Загрузить папку` и выберите папку. Если браузер не поддерживает выбор папок, SIGNAL покажет соответствующее сообщение.
4. Чтобы добавить новую версию существующего файла, нажмите по файлу правой кнопкой мыши → `Загрузить версию`. Имя файла на компьютере может отличаться от имени в SIGNAL DOCS.

Максимальная вложенность структуры — **16 уровней**. При загрузке система сначала создаёт папки, затем загружает содержащиеся в них файлы. Ход операции отображается в окне загрузки.

![addfiles_1.gif](/sgnl_docs/docs_documents/addfiles_1.gif)

![addfiles_2.gif](/sgnl_docs/docs_documents/addfiles_2.gif)

**<span style="color: #D32F2F;">СКРИНШОТ: меню добавления с командами «Загрузить файл» и «Загрузить папку», а также выбранная структура с пустой вложенной папкой.</span>**

Если в папке настроены [маски именования](#naming_masks), перед завершением операции система проверит имена файлов и при необходимости предложит переименовать их или заполнить атрибуты. В этом же окне можно указать получателей уведомления о загрузке и комментарий к версии файла, в том числе сразу для нескольких выбранных файлов.

#### 1.2. Статусы файлов
###### 1.2. Статусы файлов {#statuses}

В зоне работы с документами напротив файлов отображается статус последнего согласования, в котором участвовала версия файла. Статусы также доступны в истории версий. При нажатии на статус открывается соответствующий комплект согласования.

Для моделей дополнительно отображается значок обработки. Наведите на него курсор, чтобы увидеть статус, дату и время конвертации отдельно для **Tangl Viewer**, **Autodesk Forge** и **SIGNAL Viewer**. Сам значок показывает наиболее успешный результат обработки среди доступных просмотрщиков.

**<span style="color: #D32F2F;">СКРИНШОТ: подсказка значка обработки со статусами Tangl Viewer, Autodesk Forge и SIGNAL Viewer.</span>**

#### 1.3. Версионность файлов
###### 1.3. Версионность файлов {#versions}

При загрузке файла с тем же именем предыдущая версия сохраняется в истории. Это позволяет отслеживать изменения и при необходимости возвращаться к более ранней версии.

1. Нажмите номер в колонке `Версия`.
2. В истории отображаются все версии, автор и дата загрузки, комментарий, а также отметка `Текущая`.
3. Пользователь с доступом на редактирование может сделать старую версию текущей. Номер этой версии останется исходным.
4. Любую доступную версию можно скачать. Если версия была скопирована по результату согласования, в истории доступен переход к исходной версии.

#### 1.4. Добавление ссылок
###### 1.4. Добавление ссылок {#weblinks}

В SIGNAL DOCS можно добавлять ссылки на Google Документы, Google Таблицы и другие сторонние сервисы.

1. Нажмите `+` → `Ссылка`.
2. Укажите название и вставьте адрес в поле `Ссылка на файл`, затем нажмите `Загрузить`.
3. Google Документы и Таблицы открываются внутри DOCS, остальные ссылки — в новой вкладке браузера.

![add_weblink.gif](/sgnl_docs/docs_documents/add_weblink.gif =50%x)

## 2. Подписание документов
### 2. Подписание документов {#signing}
#### Вкладки {.tabset}
##### 2.1. Подписание ЭЦП
###### 2.1. Подписание ЭЦП {#crypto_pro}

> Для подписания документов из раздела **Документы** применяются [Настройки → Сервисы → ЭЦП](/docs/settings#services).
{.is-warning}

Для подписания необходимо установить плагин [КриптоПро](https://cryptopro.ru/).

1. Чтобы подписать несколько документов, отметьте их и нажмите `Подписать`. Для одного документа используйте контекстное меню.
2. Выберите сертификат и способ подписания. Встроенная подпись доступна только для PDF.
3. Нажмите `Подписать`.

Чтобы посмотреть подписи, нажмите значок в столбце `Подпись`. В открывшемся окне можно скачать подписанный файл или отдельные подписи пользователей в формате SIG.

![files_signing.gif](/sgnl_docs/docs_documents/files_signing.gif =50%x)

##### 2.2. Подписание ручное
###### 2.2. Подписание ручное {#faximile}

> В SIGNAL DOCS можно вставить ручную подпись из изображения или нарисовать её прямо в сервисе. Созданные подписи сохраняются для повторного использования.
{.is-info}

Откройте PDF-файл и на верхней панели выберите `Подписать` → `Ручная подпись`.

> Ручная подпись доступна только для PDF-файлов.
{.is-warning}

![faximile_start.png](/sgnl_docs/docs_documents/faximile_start.png)

Выберите сохранённую подпись, загрузите изображение с компьютера или создайте подпись вручную. Затем укажите место на листе и масштаб. Можно разместить несколько подписей на разных листах.

![faximile_mpdal.png](/sgnl_docs/docs_documents/faximile_mpdal.png)
![faximile_drawing.png](/sgnl_docs/docs_documents/faximile_drawing.png)
![faximile_position.png](/sgnl_docs/docs_documents/faximile_position.png)

После нажатия `Завершить` будет создана новая версия файла, а в колонке `Подпись` появится запись о факсимиле.

![faximile_finish.png](/sgnl_docs/docs_documents/faximile_finish.png)

### Вкладки {.tabset}
#### 5.1. Создание и копирование структуры
###### 5.1. Создание и копирование структуры {#structure_tree}

Создать структуру папок можно несколькими способами:

**Вручную.** Нажмите по родительской папке правой кнопкой мыши → `Добавить папку`.

![add_structure1.gif](/sgnl_docs/docs_settings/add_structure1.gif =50%x)

**Загрузить с компьютера.** Используйте `+` → `Загрузить папку`. В проект переносятся папки с файлами и пустые папки. Максимальная вложенность — 16 уровней. Подробнее см. в разделе [Загрузка файлов и папок](#uploadings).

**Скопировать из другого проекта.** Нажмите по папке назначения правой кнопкой мыши → `Скопировать структуру папок`, выберите исходный проект и папки. В окне копирования выберите: скопировать только папки или папки вместе с файлами и всей историей их версий.

Копирование структуры без файлов доступно также между компаниями. Копирование вместе с файлами доступно только между проектами одной компании, использующими одно S3-хранилище. Папки с файлами нельзя копировать в папку, где действуют маски именования. Одновременно в компании может выполняться только одна такая операция; следующую можно запустить после её завершения.

**<span style="color: #D32F2F;">СКРИНШОТ: окно копирования структуры с вариантами копирования только папок и папок вместе с файлами и версиями.</span>**

#### 5.2. Настройка прав доступа к папкам
###### 5.2. Настройка прав доступа к папкам {#access_folders}

> См. также видеоинструкцию по настройке прав доступа: **[Telegram](https://t.me/sgnlpro/194) [YouTube](https://youtu.be/QwunTC_lYDo?si=KzwE04tc3VoZgmfk) [Rutube](https://rutube.ru/video/328b9099b6b7bea60e0235993cab47ab/?r=wd) [VK](https://vk.com/wall-223002264_13)**
{.is-info}

Администратор проекта может назначить пользователям и ролям права на конкретные папки:

- **Просмотр** — открывать и просматривать файлы;
- **Скачивание** — скачивать файлы;
- **Загрузка** — добавлять файлы;
- **Редактирование** — переименовывать, удалять и выполнять другие действия с файлами.

Настроить доступ можно двумя способами:

1. Нажмите по папке правой кнопкой мыши → `Редактировать доступ`, добавьте пользователя или роль и выберите права. Подпапки наследуют права родительской папки.
2. Перейдите в **Настройки проекта** → **Права доступа** и назначьте роли в таблице папок.

![folder_permissions1.gif](/sgnl_docs/docs_settings/folder_permissions1.gif =50%x)

#### 5.3. Подписка на папки
###### 5.3. Подписка на папки {#subscribe}

Администратор проекта может подписать роль на события в папке. Для этого откройте контекстное меню папки → `Настроить подписки` → `Добавить роль`.

![add_subscribe1.gif](/sgnl_docs/docs_settings/add_subscribe1.gif =50%x)

#### 5.4. Корзина
###### 5.4. Корзина {#trashbin}

Удалённые файлы хранятся в корзине. Восстановить их может только администратор проекта.

1. Откройте папку, из которой удалили файл, и нажмите `Корзина` в нижнем левом углу.
2. Отметьте файлы и нажмите `Восстановить`. Для одного файла можно использовать контекстное меню.
3. Чтобы вернуться к содержимому папки, снова нажмите `Корзина`.

#### 5.5. Маски именования файлов
###### 5.5. Маски именования файлов {#naming_masks}

Администратор может задать правила, которым должны соответствовать имена файлов в папке. Откройте контекстное меню папки → `Настроить атрибуты и маски`. В маске можно использовать текст, а также символы `*` — любое количество символов — и `?` — один обязательный символ. Для одной папки можно задать несколько масок: имя должно соответствовать хотя бы одной из них. Если в текущей папке масок нет, применяются маски ближайшей родительской папки.

В маску также можно добавить атрибуты файла с типами `Текст`, `Дата` и `Список`. При загрузке, перемещении, копировании или переименовании система запрашивает значения атрибутов, формирует имя файла и сохраняет эти значения. Если значения уже содержатся в исходном имени, SIGNAL пытается определить их автоматически. Общие атрибуты можно заполнить сразу для нескольких файлов.

**<span style="color: #D32F2F;">СКРИНШОТ: редактор маски с добавлением атрибута и окно переименования нескольких файлов.</span>**
