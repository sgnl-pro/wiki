**Обозначения**
:fire: — новые возможности
:sparkles: — доработки функционала
:hammer_and_wrench: — исправление ошибок

----
**[2026.15](/general/updates/2026-15)** ^17.08.2026^

:fire: Добавили открытие моделей в SIGNAL Viewer по публичной ссылке.

----
**[2026.7](/general/updates/2026-7)** ^23.04.2026^

:sparkles: В таблицу публичных ссылок добавили поля «Тип публикации», «Опубликованная версия» и «Дата истечения», а при нажатии на имя файла он открывается в проекте.

:sparkles: При наведении на публичную ссылку добавили подсказку с информацией о ней.

:sparkles: Вывели номера версий и статусы согласований файлов при публичном просмотре.

----
**[2026.1](/general/updates/2026-1)** ^22.01.2026^

:sparkles: В настройках проекта добавили возможность отключать создание публичных ссылок.

----
**[2025.39](/general/updates/2025-39)** ^11.12.2025^

:sparkles: Добавили открытие избранных свойств при выборе элемента в режиме простого просмотра.

:hammer_and_wrench: В настройках публичной ссылки убрали кэширование поля Email.

----
**[2025.35](/general/updates/2025-35)** ^13.11.2025^

:sparkles: Доработали информационное сообщение при простом просмотре: сместили вбок и убрали возможность его закрыть.

----
**[2025.33](/general/updates/2025-33)** ^30.10.2025^

:fire: Реализовали настройку отображения элементов и их свойств в моделях для простого просмотра.

----
**[2025.32](/general/updates/2025-32)** ^23.10.2025^

:sparkles: Добавили возможность задавать дату отключения публичной ссылки.

----
**[2025.31](/general/updates/2025-31)** ^16.10.2025^

:sparkles: Реализовали вывод информационного сообщения в режиме простого просмотра.

----
**[2025.26](/general/updates/2025-26)** ^11.09.2025^

:hammer_and_wrench: Исправили ошибку скачивания папки по публичной ссылке.
